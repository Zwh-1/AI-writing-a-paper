一个在 Windows 本机运行的论文写作程序。原始资料、规则、草稿与历史版本保存在本地，模型请求发送到你配置的中转站。

源码安装与测试见 [从源码运行](docs/从源码运行.md)。Git 仓库不包含本机运行组件、模型权重、用户论文、导入原件、API 密钥或私人实测输出；文中涉及本机验收 JSON 和截图的材料留在原机器，不随源码公开。

## 快速开始

1. 便携版使用 PowerShell 7.6.5 Core 执行本目录的 `启动论文工作台.ps1`；源码用户先完成依赖安装和前端构建。
2. 打开左下角「接口与设置」，主模型为 DeepSeek，默认接口 `https://api.x5m5x.com/v1`；“GPT 备选”单独配置 EcoAPI 地址、密钥和 GPT 模型。
3. 填写自己的 API key，保存后点击「检测模型」，填写或选择中转站实际提供的 DeepSeek 模型 ID，再保存。主模型负责写作、规则提取、提纲和检查，资料总结继续使用独立的 DeepSeek 总结配置。
4. 保存后可点击「查询余额」，显示整个中转站账户余额及查询时间。余额不代表当前项目费用。默认使用 OpenAI 兼容 Chat Completions，也保留 Responses 适配。检测模型列表不等于生成能力已验证；「测试生成能力（计费）」会执行一个短请求并记账。
5. 创建或打开论文项目，修改研究简报和题目，导入自己的规范与研究资料；在「资料中心」核对规则页面，在「论文规则」确认、排除和发布条款。
6. 建立提纲，登记真实成果，再逐节写作。模型结果在「任务中心」作为候选稿展示，接受后才进入当前正文。

密钥通过 Windows DPAPI 加密，只属于当前 Windows 用户；不回传完整值，不进入工作台备份。不要把密钥写入源码或提交到版本控制。复制程序到其他 Windows 账户后，请重新填写密钥。

模型列表、余额、普通生成及流式生成共用代理设置：优先采用对应协议的代理环境变量，其次读取 Windows 系统代理，并遵循 `NO_PROXY` 和系统代理例外。仅为 localhost 设置 `NO_PROXY` 不会屏蔽中转站的系统代理。调整系统代理后，下次请求自动采用新配置。

## 本地资料

源码仓库不预置学校规范或论文原件。请导入自己的 PDF、PPTX、DOCX 等资料，并核对解析结果、条款适用范围和候选规则。导入和候选提取不会自动将页面标为人工核对通过。

原件通过内容哈希存储。同名内容发生变化会形成新版本；重复内容去重。再次启动不会重复导入已经就绪的资料。

## 使用流程

### 研究准备

- 在项目概览填写题目、研究问题、目标、方法、范围、作者、学校与导师等信息。
- 在研究与成果登记计划、实现和测量状态；关联实际截图、代码说明、原始数据和测试记录。
- 在编辑器选中正文段落后，可以关联原文来源或研究事实。研究覆盖表显示章节、有关联依据的段落、原文和事实数量。
- 修改事实、规则或相关章节后，系统提示后续内容需要复查。

### 规则准备

1. 将正式要求的资料用途设为「论文规则」；写作范例设为「写作示例」，研究文献设为「研究文献」。单份文件可以先按主用途管理，具体条款另行分类。
2. 打开资料，核对文字、讲者备注与原始图片。PDF 可查看原页；PPT 提供提取的图片和原文件下载，暂不声称完整还原每页 PowerPoint 排版。
3. 对图片中的要求，优先使用不联网的「本地 OCR」或文件级批量识别。系统需要已安装中文/英文Windows OCR语言；当前机器已验证可用。也可执行「API 图片识别」，在任务中心查看候选，再人工转录、确认。视觉调用需要所选模型实际支持图像；也可直接人工转录，不产生 API 费用。
4. 排除不适用页面时填写理由；可以将不作为本项目规范的文件改为示例等用途。
5. 点击「从课件整理候选」，逐条确认强制要求、建议、反例及适用范围，解决冲突。
6. 发布规则包。未完成解析或核对的规则来源、冲突的强制数值条款会阻止发布。

规则包是不可变快照。修改候选条款后需重新发布，旧稿与旧导出仍关联原版本。每次模型正文操作明确加载适用规则，并记录实际请求清单；格式专属条款需结合排版配置和人工检查。

### 写作与修改

- 支持生成本节、定向修改、扩写、压缩、翻译与连续生成候选。
- 提供类型提纲及 AI 提纲候选；候选接受前可编辑，采用时追加章节，不覆盖现有正文。
- 编辑器支持标题、段落、列表、表格、引用、图表和基础数学文本。
- 自动保存形成不可变版本；保存失败时明确提示，并保留本机应急草稿。切换后或重新打开时可选择恢复。
- 段落锁定同时由编辑器与后端验证。可选择仅改写当前或连续选中的段落。模型修改保留锁定段落、已有表格和图表，用户仍需查看排布是否合适。
- 候选稿可整节接受、明确追加选中段落，或在差异面板选择被替换原文与候选，在原位置替换。基础正文、规则或研究事实已变化时拒绝静默覆盖。
- 「已有草稿」可从 TXT/MD/PDF/DOCX 建立正文版本。DOCX 支持段落、基础样式、普通表格、内嵌图片及数学文本；复杂公式、合并单元格和引用编号需导入后核对。

### 文献与证据

- 支持手工书目、BibTeX/RIS 导入和可选 Crossref 元数据查询。
- 元数据候选与真实全文核查分开；仅元数据、仅摘要、全文分别标记。
- 正文引用关联稳定文献 ID。序号在导出时按实际引用顺序计算；书目修订保留快照。
- 引用可 AI 辅助核对，也可记录人工支持、部分支持或不支持。AI 判断不会自动变成人工确认。
- 最少文献数量检查按当前正文实际引用并去重的文献计算，不能靠登记未使用书目通过。
- 未完全自动化的内容与格式规则在报告中显示「待判断」，不会被模型一句“已遵守”变成通过。

### 数据与图表

可导入 CSV/XLSX，执行实际描述性统计，保留输入文件哈希、行数、缺失值和结果。支持从数值列生成分布图并关联到正文。不会执行任意模型生成代码，不会自动编造统计检验或实验结果。

### 检查与交付

- 程序检查、AI 语义检查、导师意见与人工复查分别记录。
- DOCX 按当前排版参数生成，支持上传样式模板。当前模板用法继承样式、页面与页眉页脚，并清理示例正文；复杂封面占位、分节和特定学校特殊版式需要专项适配与验收。
- 导出包括 DOCX、Markdown、PDF（可用时）、检查报告、版本清单、段落证据映射和交付 ZIP。
- 无 LibreOffice 时，内置 ReportLab 可使用本机中文字体生成独立 PDF 排版。它与 Word 的分页可能不同，不代表 Word 目录和页码已验证。
- 在学校指定软件更新目录、页码，再逐页检查。程序不会把“文件生成成功”当成“已通过视觉验收”。

## API 费用与异常

Token 单价默认未配置，费用显示未知。请按中转站账单设置币种、输入/输出单价。项目初始预算 20、单次未知费用预留 2 是本地控制参数，不是服务商真实价格。

未知用量保留预留额度；可在设置页按实际账单登记。预算不足会停止后续模型调用。请求已发出但没有最终响应时，标记「远端状态未知」，不会无条件重发；手动重试需知悉可能重复计费。

已计费且返回无效结构或错误来源的输出保留为不可直接接受的原文候选，便于人工整理。取消会停止后续步骤，不能保证撤销服务方已经产生的费用。

## 启动、停止与恢复

所有 Shell 会话须使用 PowerShell **7.6.5 Core**，脚本开头严格检查版本，不会自动降级。

```powershell
& 'D:\桌面\论文\paper-workbench\启动论文工作台.ps1'
& 'D:\桌面\论文\paper-workbench\停止论文工作台.ps1'
```

便携版自带 `.runtime/python`、本地依赖和预构建前端；源码安装使用自己的 Python 环境并构建前端。数据默认保存在本目录 `data`，该目录不进入版本控制。

备份包含所有项目、规则、正文与原件，默认不含 API key。恢复会核对哈希并创建隔离副本，避免覆盖当前工作。用另一个端口查看恢复目录：

```powershell
& 'D:\桌面\论文\paper-workbench\启动论文工作台.ps1' -Port 8767 -DataDirectory '恢复结果中的目录' -SkipSeed
& 'D:\桌面\论文\paper-workbench\停止论文工作台.ps1' -Port 8767
```

如果需要更换正在使用的数据目录，先停止对应端口的工作台再启动。服务仅监听本机回环地址，不对局域网开放。


## 0.2新增功能入口

- **论文规则 → 规则执行设置**：配置字数、文献比例、必需章节/词项、图表数量、排版参数等检查器，设置操作范围与条件，保存后重新发布规则包。
- **资料中心 → 批量图片识别 / 资料页 → 本地OCR**：本地识别不发送中转站；候选保留页码和原始识别信息。资料单元可以分别标注正例、反例、研究证据等。
- **提纲与计划 → 提纲层级、排序与依赖管理**：设置父章节、多个前置章节，统一保存；程序拒绝循环。归档保留正文，存在子章节或依赖时需先处理。
- **写作工作台**：可只改写选中段落；任务结果的差异面板可在原位置接受部分候选；审阅后记录当前版本的人工确认。
- **排版与交付 → 规则与排版联动**：预览并应用生效排版要求，保存/切换格式与模板方案；DOCX导出后检查实际属性。
- **修改与检查 → 人工规则核对**：记录核对依据，绑定当前章节和输入快照；正文或资料变化后自动失效，不能覆盖程序确定性失败。
- **项目概览 → 项目准备与交付缺口**：查看尚未核对的规则页、未写章节、未审阅内容及过期提示。
- **资料中心 → 资料检索召回评测**：提交真实问题与标准来源，保存逐条Recall@10结果。

## 开发与测试

```powershell
& '.\.runtime\python\python.exe' -I -X utf8 '.\runner.py' test
npm run build --prefix '.\frontend'
```

- `backend/app`：项目、来源、规则、研究、正文、任务、检查、导出与模型适配。
- `backend/migrations/001_initial.sql`：初始数据库结构；高版本数据库会拒绝被旧程序静默降级。
- `frontend/src`：实际页面、编辑器、锁定插件和样式。
- `prompts`：写作提示词和响应契约。调用记录保留提示词哈希及实际版本。
- `tests`：后端业务与三个协议的模拟契约测试、真实浏览器流程。
- `docs`：使用、验证、实现范围与样本截图。

模型适配支持 Chat Completions 和 Responses。DeepSeek 和 GPT 各自保存接口、加密密钥、模型和费用参数；能力测试和实际业务调用分开记录。

## 实现边界

本版交付本地单用户写作流程和部分研究增强功能。当前检索采用中文分词、术语扩展与 SQLite 全文索引；没有把神经向量检索列为启用条件。

未包含：多用户实时协作、云端自动同步、通用复杂学校模板的自动适配、PPT 原始整页版面的本地重建、复杂公式与脚注的无损往返编辑。扫描/OCR已接入Windows本机识别，可选模型视觉或人工转录；识别结果仍需核对。

这些边界会在对应界面或报告中保留，不影响本地资料管理、规则发布、写作审阅和基础交付。完整验收范围见 `docs/实现与验收说明.md`。

## 0.3.0高级功能

左侧“高级研究与协作”提供六个入口：混合检索、整页与表格、统计与系统采集、公式与保真文档、流式与恢复、协作与云同步。首次使用先检查功能状态；模型索引、Office渲染与统计任务均可在任务中心查看。

中文向量与交叉重排在本机执行，不使用中转站key。程序包含公共模型与浏览器运行组件，论文资料、密钥、账号和登录态不进入便携包。浏览器组件缺失时使用“准备截图浏览器.ps1”；容器代码执行使用“准备隔离执行环境.ps1”，不允许在宿主机降级执行。

保留复杂学校封面和分节时，请在正式DOCX模板正文处提供唯一 `{{PAPER_BODY}}` 段落，再选择保真排版。全文内容、引用与正式版面仍需本人和目标软件验收。

协作默认只监听127.0.0.1:8774，首次账号及密码由用户自己建立。协作AI默认预算0，未配置规则或预算不能生成候选。远程部署见 `deployment/README.md` 与“部署协作服务.ps1”；不要把主工作台的本机共享会话直接当作多用户登录。

云同步使用独立口令加密整个项目资源快照，ETag检测其他设备更新；正文与资料冲突分别保留。新设备可从加密包导入原件和引用，源文件和修订不会被盲目覆盖。
