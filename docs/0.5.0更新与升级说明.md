# 砚台 · 论文工作台 0.5.0

发布日期：2026-10-24。应用版本从0.4.1更新为0.5.0，前端、后端和便携包使用同一版本号。

## 本次更新

- **文献知识库**：PDF原件、书目、原页、知识片段与引用来源统一关联。支持ZIP文献包预览、批量导入、重复检测、原文关联、书目编辑和术语增删改；完整著录和导入来源保留。
- **完整RAG检索链路**：BM25与Dense Retrieval分别召回，经RRF融合后由独立Cross-Encoder重排，再返回Top-K。界面显示实际候选数、重排数量、排名变化和耗时。重排失败时保留RRF结果并标明实际路径。
- **本地持久索引**：全文和向量索引保存在本机，绑定模型、文本及原件版本，支持增量更新。已归档、排除或禁止外发的资料按相应范围处理；既有来源编号继续用于引用。
- **英文摘要翻译**：直接翻译同一项目已保存的中文摘要。中文原文缺失时不创建翻译请求；中文版本变化后拒绝采用旧译文。连续生成先处理正文和中文摘要，英文摘要在中文候选采用并保存后翻译。
- **工作区交互**：提纲计划支持多项前置依赖、保存状态与失败恢复；文献、资料和规则工作区支持筛选、分页、原文追溯、键盘弹窗及手机布局。
- **资料与规则工作区**：整合共享AI托管状态、预算与例外入口，保留来源核对、规则归并、发布与费用恢复记录。机器处理和人工核对继续分别标记。

## 升级与数据

本机运行目录中的版本已更新，继续使用原数据目录。更新前创建数据库副本，原始论文、导入文件、书目、来源编号及费用记录不因应用版本更新而重置。

数据库版本仍为7；知识库登记表通过`011_reference_knowledge.sql`追加建立，不修改既有正文或重建引用编号。应用版本、数据库版本、模型配置和写作控制器指纹分别管理；升级不会将旧稿或旧模型资格自动标记为当前人工验收通过。

便携包包含本机运行组件、前端构建产物和已安装的本地检索模型。用户论文、项目数据库、凭据及本机实测输出不包含在程序包中。新目录启动会使用自己的数据目录；若需要继续现有论文，使用原工作目录，或从工作台的完整备份恢复。

启动仍要求PowerShell 7.6.5 Core。更新服务后通过启动入口重新打开工作台，以取得当前本机会话。

## 验证与边界

版本交付核对前后端与锁文件版本、前端构建、后端回归、本机服务版本、页面页脚及便携包完整性。文献知识库和重排链路另有真实本地模型与浏览器验证记录，位于本机`.runtime`。

Cross-Encoder分数是相关性分数，不代表事实正确率。程序测试、实际模型打分和排名变化不代替人工语义相关性标注、论文通读或学校版式验收。付费模型调用继续由相应写作或AI处理操作发起，版本更新和本地检索不会自动生成论文正文。
