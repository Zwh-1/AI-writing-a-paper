# 英文摘要翻译

英文摘要由已保存的中文摘要直接翻译，保留同一研究内容、数值、结论和关键词，不作为独立摘要生成。

1. 完成中文摘要并保存正文。AI 候选需先审阅并采用，才能成为翻译原文。
2. 在「提纲与计划」的英文摘要行点击「翻译中文摘要」，或在写作工作台使用同名操作。
3. 在任务中心审阅译文候选后采用。候选不会自动覆盖现有英文正文。
4. 中文摘要修改后重新翻译。排队任务及待采用候选会核对中文原文版本，旧译文不能按新原文采用。

连续生成包含中文摘要时，会先建立其他章节及中文摘要候选，并明确跳过英文摘要；中文摘要候选采用并保存后再翻译。如果只选择英文摘要且中文原文已保存，则建立翻译任务。

英文摘要不单独设置目标篇幅；提纲列表不再为其显示独立字数目标。已有手工正文保留，重新翻译仍需审阅后采用。多篇中文摘要可通过英文摘要的前置依赖指定唯一原文；原文缺失、为空或来源不明确时不会调用模型。翻译沿用已配置模型，调用会按原有费用规则记账。

实现以中文摘要完整正文为输入，不通过研究检索另写一篇摘要。模型输出受结构、来源与版本检查，语义忠实程度仍由审阅确认。
