# 功能产物互通方案

日期：2026-11-02

## 问题与目标

已有功能分别管理资料总结、阅读批注、译文、导读、对话、随记、图表、研究事实、统计结果与正文。部分页面虽共用服务，但用户仍需复制内容；原页面产物没有统一目录，下游功能无法直接选择。现有来源追踪、资产版本、草稿采用和跨页导航作为基础继续复用。

目标是形成可实际操作的链路：**功能产出 → 项目产物目录 → 指定用途 → 目标页面消费 → 来源变更提示**。复用沿用原对象身份和版本，不自动增加人工核验等级。

## 方案

1. 以适配器汇聚资料与总结、书目、批注、译文、导读、助手回复、随记、网页、资产、研究事实、统计分析、Wiki、图谱论断和当前章节；原业务仍负责保存。
2. 使用 `project_id/type/id/version` 标识输入，服务端重新读取内容，不接受客户端提交的产物正文作为依据。支持分页、搜索、分类和按当前章节筛选。
3. 文本产物可转成带来源的随记、富文本资产和待采用的章节草稿；图表通过既有持久插入意图进入指定章节。草稿先预览，采用时重查正文与来源，保留历史版本和锁定规则。
4. 学术对话直接选择项目产物，实际模型请求记录所选对象的版本与未核验身份；请求前后检查来源。模型调用仍由用户点击发送触发。
5. 项目导航增加“产物与互通”；写作、文献、研究助手和成果页面可以进入相同目录，来源卡片能返回产物及原文。跨页接收选中的随记、对话材料和章节。
6. 补齐总结、事实和统计结果的来源版本适配，并保留资产编辑后的来源关系。文件外发权限通过依赖链逐层校验。来源修改后不能采用旧草稿。

## 实施与验收

不新增平行存储，不迁移或重置用户数据库。转换结果保存到已有研究记录、资产与草稿服务；相同版本和目标的重复转换复用已有结果。完整包和研究记录协作继续校验引用对象。

验收覆盖：总结/译文/统计结果转随记；随记或研究事实转资产并进入对话；多个产物生成草稿并采用；图表跨页插入；旧版本、跨项目和本地权限拦截；重复操作与原有工作流回归；前端构建及浏览器桌面和窄屏操作。
