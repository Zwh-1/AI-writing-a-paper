文献页面功能核查与修复（2026-10-31）

截图中的页面已有前后端实现。本次针对实际操作、数据持久化和跨页回查进行验收，修复了三处影响使用的问题。

| 修复 | 原先的行为 | 修复后的行为 |
| --- | --- | --- |
| Wiki 搜索 | 检索后统一刷新重新加载全部页面，覆盖搜索结果；打开详情也会丢失筛选 | 保留已提交的关键词；检索、打开详情、保存和发布修订后保持当前结果范围 |
| 证据检索原件范围 | 列表按原件筛选，但搜索请求未携带原件范围，接口也未转交该参数 | 前端发送原件 ID，接口转交统一检索服务；检索严格限定所选原件，并拒绝另一项目的原件 |
| 阅读记录顺序与定位 | 已读范围按记录时间和随机 ID 排列，恢复后可能乱序；同页多个单元的引句选项难以区分 | 按原文单元及字符位置排列，已读原文和引句选项均显示单元编号 |

| 页面 | 本次实际通过的浏览器流程 |
| --- | --- |
| 文献书目 | 修改作者并保存，书目继续关联原件 |
| 问题阅读 | 选择原件、建立问题与章节阅读记录、读取指定范围、保存逐字引句核对、关闭后继续原记录 |
| 原文与证据 | 按所选原件检索、读取完整上下文、保存核对状态、选择并持久保存章节证据 |
| 全文与向量检索 | 检索返回原文片段，从命中结果打开原件查看器 |
| 图谱与 Wiki | 无匹配查询、关键词筛选、打开知识页面、回查出处、保存修订候选、发布修订、关系探索、执行章节阅读计划 |
| 统一术语 | 新增、编辑、刷新后读回、删除；后端额外验证项目隔离 |
