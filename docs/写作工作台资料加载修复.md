# 写作工作台资料加载修复

2026-10-26，修复写作页“资料依据”空白、文献列表正常显示的问题。

原实现仅在点击搜索图标时读取研究文献，没有加载当前章节已关联原文。章节任务保存的是证据记录编号，须先解析到原文来源编号，才能正确显示内容及关联段落。

现在进入写作页会自动读取已发布章节任务和当前正文关联的原文；尚无关联时显示最近导入的可用原文。搜索支持回车，覆盖规则、示例、研究文献及数据，并保留资料用途标签。可以直接打开原文查看器或关联当前段落，原文核对继续使用已有文档状态。

加载中、请求失败、搜索无匹配分别显示；失败可重试。切换章节或项目时重置查询并取消旧请求，结果列表独立滚动。已停用文件、人工排除页面和其他项目资料不参与展示。本地读取不调用模型。

验证：24 项后端测试通过；前端类型检查与构建通过。浏览器使用实际项目确认摘要的 11 条关联原文可自动加载，并检查原文打开、正确来源编号关联、文献页签、回车搜索、失败恢复、延迟请求与章节切换及手机和平板布局。浏览器检查未修改实际项目，也未调用模型。
