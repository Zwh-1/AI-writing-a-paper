# 单包便携版与体积优化

> **0.7.3 更新**：本次按完整整合包发行，主程序、知识图谱运行库、截图浏览器及默认本地模型合在一个 ZIP 中，不再拆分交付。此配置不限于 500 MB。下文保留历史小包配置与开发选项说明，当前使用方法见[0.7.3 完整整合便携版](0.7.3完整整合便携版使用说明.md)。

2026-10-27 调整。默认仍发行**一个完整 ZIP**，所有业务功能保留，截图浏览器和两个默认本地模型在首次启动后自动下载，无需另找组件包。默认发行 ZIP 必须严格小于 **500,000,000 字节（500 MB）**。

默认包内置 Python、全部业务运行依赖、构建后的前端、Node、TypeScript 语法解析和 PowerShell 7.6.5 Core。解压后双击 `启动工作台.cmd`，后台自动准备 Chromium headless shell、BGE small 中文向量模型和 BGE reranker 重排模型；停止工作台时双击 `停止工作台.cmd`。网络失败时下次启动会重试，也可双击 `准备便携资源.cmd`，已校验资源可复用，模型下载支持断点续传。

保留此前的体积优化：Node 只带一份；Python 依赖按实际 `advanced-deps` 加载优先级去重；不附送前端源码、开发依赖、测试和验收资料。进一步剔除 pytest、pluggy、iniconfig 及其元数据、Python 类型声明、source map 和 fontTools 的 C 头文件与源码；TypeScript 只保留实际语法解析用的 `typescript.js`、包元数据及许可证，剔除编译器 CLI、语言服务入口和声明库。所有后端业务代码、统计库、OCR、ONNX 和导出库继续随包保留。标准 ZIP 使用 Deflate 压缩，可用系统解压工具展开。

协作网关实际使用的独立 HTML 页面单独映射到发行包的 `frontend/collaboration.html`，避免排除整个前端源码目录时漏掉协作入口；不附带其他前端开发源码。

Playwright 仅保留浏览器核心运行库与 API 入口；下载浏览器使用 `playwright-core/cli.js`，不依赖 Playwright 测试运行器和 MCP 测试目录。

原 0.6.1 单包实测为 702,067,062 字节，其中本地模型约 266.7 MiB、截图浏览器约 114.0 MiB（均为压缩后的内容）。因此核心体积优化是把可自动恢复的公共资源改为首次启动下载；移除少量项目源码不能解决主要占用。首次下载后的解压目录占用不受发行 ZIP 的 500 MB 限制。

AI 写作与生图仍需用户填写相应接口、key，并可访问服务。Windows OCR 的语言包、需要容器隔离的实验所用 Docker 引擎、与学校指定 Office 完全一致的渲染环境属于系统能力，不会通过捆绑程序资源假装已安装。普通 Word 文件导出本身不要求安装 Word。

## 开发打包

在已准备程序运行时、前端构建和 PowerShell 7.6.5 分发文件的源码目录中执行；默认打包不要求本机已有模型和浏览器二进制：

```powershell
if ($PSVersionTable.PSVersion.ToString() -cne '7.6.5' -or $PSVersionTable.PSEdition -cne 'Core') { throw 'Required PowerShell 7.6.5 Core.' }
& './.runtime/python/python.exe' -I -X utf8 './scripts/package.py'
```

默认生成 `砚台论文工作台_0.6.1_完整便携版.zip`，不生成拆分组件。`--audit` 只检查文件选择和原始体积。`--max-mb` 可指定更严格的十进制 MB 上限；达到上限会拒绝发布，保留原有发行包。`--profile offline` 显式生成包含全部浏览器和已校验模型的完整离线版，可通过 `--max-mb` 单独限制体积。旧的 `--profile portable/browser/models/all` 仅保留作开发维护选项。

打包后重新读取 ZIP 并核对逐文件 SHA256，同时报告各部分压缩前后的体积。单包须在独立目录解压，验证首次启动自动准备资源，再使用该目录的 PowerShell、Python、Node、浏览器和模型验证检索、实际截图、图表、统计和 Word 导出。

详细操作见《单文件便携版使用说明.md》。
