# 逐章写作与上下文衔接

写作工作台按章节生成、审阅和采用候选，生成、定向修改、润写、扩写和压缩均先读取所有未归档章节已保存的完整正文。输入包括全部前章、全部后章、当前章完整旧稿、全篇提纲和项目术语表。不会只读取章节首尾、相邻章节或检索命中的局部片段。

选段改写保留同样的全文输入，并额外标记选区前后各最多两个完整正文块，以帮助定位。模型只返回选区替换稿，选区外正文由程序保留。润写使用[独立学术润写规范](独立学术润写.md)，只加载明确适用于“润写”的项目规则，不继承修改专用规则。

“全文上下文”显示已有正文的章节数、提纲章节数、总字数，并可展开查看各章字数。提交前先保存当前编辑内容，再刷新清单。没有已保存正文时明确显示“目前只有提纲与研究资料”；导入资料中心的参考文件不等于当前论文正文，未采用的候选也不会被当作正式全文。

全文原文不截断、不自动摘要，也不因预算不足而悄悄删除某一章。全文本身或加上必要规则、证据后超过所配置接口预算时阻止调用并说明原因；某章的派生来源禁止外发时同样明确阻止。界面预检估算正文所需的最低输入规模，完整请求仍会在发送前按规则、证据和协议开销检查。

候选记录实际读取的各章版本与全文字数，以及提纲、术语快照。任一参考章节修订、原来空白的章节补写、提纲或术语变更后，采用检查会要求重新生成或复核。有据写作在正文生成、语义核验和篇章衔接阶段读取已保存全文；早期证据调查与独立句子批次仍按其阶段范围工作，不假称这些阶段已经通读全文。

验证使用隔离数据库和模拟模型，逐一截获五种操作真正传入模型适配器的请求，比较八章完整正文与原文逐字相等，覆盖长段落、中部文字、较远后章与选区外正文。另检查字数清单、版本失效、权限阻止、超预算时没有模型调用，以及选区外内容保留。全文输入保证材料覆盖范围；实际生成的表达与推理质量仍需审阅候选。
