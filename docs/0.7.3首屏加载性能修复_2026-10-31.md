# 0.7.3 首屏加载性能修复

日期：2026-10-31。

## 现象与原因

真实项目的首次请求测得资料列表接口约 12.5 秒、规则目录接口约 14.4 秒；首页还每 3 秒扫描一次绑定的项目目录。慢响应期间数据计数显示横线，资料页持续显示读取状态。

资料页返回 57 份资料时，/projects/{pid}/files 为每份文件逐一计算总结状态，而每个状态又重复查询相同的项目预算。首次剖析发现单次响应内累计计算预算 58 次，单是预算查询耗时约 8.46 秒。规则页载入目录时，条款整理及发布诊断产生数千次小型 SQLite 查询，各查询分别建立连接。

## 修复

- 批量资料总结状态在一次只读数据库会话中加载；项目预算每批只计算一次，并在每份资料结果中沿用同一快照。
- 规则条款、出处和诊断在同一只读连接中查询，避免数千次重复连接和 SQLite 初始化。
- 项目外部目录变更检查延后到工作台打开 5 秒后，随后改为每 15 秒检查；浏览器恢复焦点时再安排一次延迟检查，避免它与首屏请求竞争。

预算仍按项目生成任务判断；费用记录和预算值没有被修改。资料总结的逐项状态及收费限制保持原有含义。

## 实测

同一 0.7.3 项目、同一台机器、本地浏览器直接读取，修复前后对比：

| 请求或页面 | 修复前 | 修复后 |
| --- | ---: | ---: |
| 资料页首条资料可见 | 12.5 秒接口；约 12.5 秒页面加载 | 0.68 秒资料接口；0.94 秒首条资料可见 |
| 规则页首条规则可见 | 14.4 秒接口；约 15.2 秒页面加载 | 2.60 秒规则接口；3.40 秒首条规则可见 |
| 文献书目页首条文献可见 | 未发现同类慢请求 | 18 毫秒书目接口；0.87 秒首条文献可见 |
| 项目文件关联 | 0.97 秒 | 0.23 秒 |

此外，57 份资料的总结状态批量查询由 58 次预算计算降为 1 次：首次 1.21 秒，缓存预热后 0.17 秒。规则工作区只读连接的性能回归检查通过。

页面耗时测至代表性内容首条出现。不同磁盘、同时运行任务数量和资料规模会改变实测时长；此结果不代表所有电脑都具有相同速度。

## 验证

- 资料总结、账单、资料解析和来源联动测试：62 项通过，其中新增回归断言每批只计算一次预算。
- 规则目录、重复条款、发布冲突和批量有效性测试：74 项通过，其中新增回归断言完整规则工作区只打开一个只读连接。
- 浏览器实测资料、规则及书目首屏加载；捕获的页面 JavaScript 错误为零。
- 单 ZIP 0.7.3 包和此前独立 390px 多页面布局验证记录见 docs/v0.7.3-package-verification.json 与 .runtime/release-v073-qa/。
- 本次未发起模型请求，也未改变真实论文数据、预算或账单依据。
