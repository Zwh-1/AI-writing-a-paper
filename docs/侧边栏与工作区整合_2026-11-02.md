# 侧边栏与工作区整合

项目侧边栏按工作流程收拢为五个主入口。每个工作区使用与文献资料、论文规则一致的页内卡片导航，具体功能保留在对应子页面中。

| 主入口 | 页内功能 |
| --- | --- |
| 项目概览 | 项目简报、准备情况与研究进度 |
| 文献资料与规则 | 资料中心、论文规则、文献与知识 |
| 提纲与写作 | 提纲与计划、写作工作台、有据写作 |
| 研究与协作 | 研究与成果、研究助手、产物与互通、高级研究与协作 |
| 检查与交付 | 修改与检查、排版与交付 |

接口与设置继续位于侧边栏底部；任务中心和费用入口位于顶部。

侧边栏显示当前子页面，顶部面包屑同时显示工作区和页面名称。离开后重新打开工作区，会返回该论文项目上次访问的子页面；不同论文的记录独立保存。原有来源、章节和产物跳转仍然直达指定页面。

页内导航复用 `WorkspaceNavigation`，分组、标题和功能说明集中在 `workspace/projectNavigation.ts`。页面加载期间仍可切换同组功能，键盘切换后焦点保留在当前功能卡片。窄屏保留可读的功能名称，四项功能的工作区在手机上采用两列布局。

## 验证入口

- `npm run build --prefix frontend`：类型检查与生产构建。
- `tests/serve_navigation_fixture.py`：使用独立临时数据库创建两个合成项目。
- `tests/sidebar-workspaces-browser.cjs`：验证所有分组和子页、面包屑、位置记忆、项目隔离、跨页跳转、键盘与不同屏幕宽度。

回归测试使用本地合成项目，不调用真实模型。截图及结果写入 `.runtime/sidebar-workspaces-20261102`，不进入源码交付。
