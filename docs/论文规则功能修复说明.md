# 论文规则功能修复说明

修复日期：2026-10-21。适用于本机工作目录中的现有 0.3.3 程序。

## 已修复的问题

- 功能入口：AI 整理默认显示文件、片段上限和起始位置；规则执行设置显示条目数量、展开箭头及配置提示。
- 新增与编辑：按用户所选状态保存规则，不再把所有新增要求直接标为已确认。条款编辑支持全部现有检查器，以及结构化参数、适用操作、条件和采用依据。改为人工核对时清除旧检查键，避免遗留错误冲突。
- 规则来源：可打开来源片段，并直达材料原页，沿用现有原文核对功能。发布前列出尚未核对的具体页面。
- 发布流程：页面和后端使用同一套发布检查，展示解析、覆盖、确认、失效来源与强制冲突问题；保留生效快照，并提示尚未发布的修改。
- 冲突处理：展示涉及的具体条款，支持编辑取值或排除。兼容的字数上下限，以及适用写作操作互不相交的条款，不再被错误阻止发布。只填写采用依据不会绕过仍存在的强制冲突。
- AI 分批：按材料统计来源片段，支持指定起点和选择下一批。入队时冻结该批来源 ID；重复点击不会重复排队。仅限本地材料在提交前阻止模型整理，已排除页面不参与整理。
- 操作反馈：当前页显示本地 / AI 整理任务进度、结果和取消入口；提供搜索、来源筛选、批量排除、恢复待确认。确认条款仍需逐条核对。
- 读取与显示：合并规则条件查询，减少大量候选条款的重复数据库读取；调整手机端生效版本提示和表单布局。

## 使用顺序

1. 在“发布前检查”查看未完成事项，可直接打开待核对材料页。
2. 用“从课件整理候选”进行本地整理；需要语义梳理时，在 AI 面板选文件和批次，点击明确标有“计费”的按钮。
3. 对照来源，逐条修改性质、状态、范围和执行方式。正反例及“待判断”性质不会进入规则包。
4. 处理冲突后发布。后续写作加载已发布快照；进一步编辑时需要重新发布。
