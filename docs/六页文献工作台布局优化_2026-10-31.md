# 六页文献工作台布局优化

日期：2026-10-31。布局依据：用户选择“工作台式：目录、内容、详情分栏，适合频繁查阅”。

六个入口沿用原来的功能范围，统一为左侧定位内容、中间阅读或编辑、右侧查看当前条目信息与操作。桌面保留三栏，空间不足时把辅助信息放到内容下方；手机按目录、内容、辅助信息的顺序排列。

| 页面 | 内容与交互调整 |
| --- | --- |
| 文献书目 | 文献目录与完整详情分开。左侧保留题名、作者、年份和搜索，分类、语种及核对状态收在筛选中。中间展示完整题名、著录信息和文献总结，右侧集中原文、书目核对、阅读和导入入口。 |
| 问题阅读 | 用书目题名代替长文件名。选择文献后在当前页面建立阅读问题，阅读原文与核对记录拆成两个步骤。右侧按当前文献展示已保存记录、阅读顺序和原件入口；恢复记录保留原件信息。 |
| 原文与证据 | 左侧放原件、检索和原文单元目录。选中单元后在中间读取原页及上下文，再切换到核对与修订。右侧集中章节证据、分段工具、核对进度和正文引用。章节证据尚在读取时明确显示状态并暂时禁用勾选及保存。 |
| 全文检索（证据页内） | 检索结果作为左侧目录，选中后在中间阅读完整片段并回查原页；检索过程、索引统计放到右侧按需展开。 |
| 图谱与 Wiki | 左侧按主题和题名定位，中间阅读知识内容，右侧显示发布状态、版本与追溯。完整题名和原文出处都保留；长文件名不再占据主题目录。 |
| 统一术语 | 改为术语目录与直接编辑的工作台，增加译法预览、搜索和保存状态。术语切换时保护未保存的修改。 |
| 处理与维护 | 八类维护工具改为任务目录，一次显示当前任务，切换后保留已填写内容。用“查询与阅读计划”“合并页面修订”等名称解释用途，右侧保留核对人、说明和预算。构建、版本检查和评测均补充操作说明，高级索引设置按需展开。 |

顶部原有的大块项目联动和重复统计收成可展开的状态行。功能导航保持六个入口，减少到达正文前的滚动距离。正文与辅助文字采用不同字号、行距和对比度；完整文件名及技术数据仍可在原件信息和展开项中查看。

## 验证

- TypeScript 检查与 Vite 生产构建通过。
- 独立合成项目完成术语增改删、书目修改、问题阅读、原文核对、章节证据关联、全文回查、Wiki 修订发布及本地查询的浏览器回归；没有向真实论文写入合成数据。
- 真实项目的六页分别检查 1600、1280、1024、768 和 390 像素宽度，目录、内容和辅助信息可达，无横向溢出。
- 八类维护工具逐一切换，确认一次只展示当前工具、已填写的问题仍保留。
- 规则工作区共用的知识页面另外核查，确认首次进入也能加载分栏样式。
- 未发起收费模型调用。原件、正文、书目、费用依据和预算仍使用现有数据。
