# 功能产物互通实施与验收

## 使用入口

启动更新后的源码工作台，打开 **研究与协作 → 产物与互通**。写作工作台、文献与知识、研究助手和研究成果也提供“复用项目产物”；单份资料总结提供“复用这份总结”。

在目录中搜索、按类型筛选并勾选产物，然后选择用途。正文草稿先预览，点击“核对并采用草稿”才生成正文版本。图像和原生三线表先转交指定章节，再在写作工作台点击“插入到当前光标”。学术对话会接收所选产物，点击发送后读取真实内容。

## 已实现的范围

目录汇聚 15 类对象：原始资料、资料总结、文献书目、思维随记、阅读批注、学术译文、阅读导读、助手回复、交互网页、研究资产、研究事实、统计分析、Wiki 页面、图谱论断、当前章节正文。

| 流转 | 实际行为 |
| --- | --- |
| 文本产物 → 随记 | 服务端读取指定版本，保存内容和来源关系；可关联章节 |
| 文本产物 → 资产 | 进入所有页面共用的资产库；编辑后仍保留来源 |
| 产物 → 学术对话 | 跨页保留勾选项，模型输入包含实际内容、类型、版本和未核验身份 |
| 多个文本产物 → 章节 | 创建待采用草稿，保留原正文；采用时检查正文版本、来源和锁定约束 |
| 图像 → 正文 | 持久待插入记录固定目标章节、正文版本和资产版本 |
| 三线表 → 正文 | 保留原生表格节点、单元格、表题、表注和资产版本，可继续编辑并导出 |
| 上游变更 → 下游 | 总结、事实、资产、随记等按实际来源传播失效提示；旧候选不能静默采用 |
| 产物 → 来源 | 来源卡片回到原文、章节或对应产物目录 |

每次选择最多 20 个对象，合计正文最多 40000 字符；超过范围明确提示用户缩小选择。转换和插入不调用模型。转换不会把个人随记、模型输出或计划中的研究事实提升为人工确认的证据。

## 实现位置

- `backend/app/product_service.py`：聚合目录、搜索分页、版本内容读取、转换与草稿编排。
- `backend/app/product_sources.py`：既有总结、研究事实、统计结果的版本、来源与反向影响适配。
- `resource_refs.py`、`research_relations.py`、`knowledge_lineage.py`：共享来源、原件集合、动态状态与变更传播。
- `asset_service.py`、`workspace_intents.py`：资产编辑保留来源，插入固定历史版本，三线表使用原生节点。
- `assistant_service.py`、`tasks.py`、`writing_agent/provenance.py`：实际模型上下文与请求清单，以及派生正文的来源权限。
- `frontend/src/products/`、`frontend/src/api/products.ts`：共享目录、选择器、跨页入口和接口。
- 原有写作、总结、文献、研究助手、成果页面直接组合上述实现。

新增接口为 `/api/v2/projects/{project_id}/products`、`products/preview`、`products/reuse`；沿用统一鉴权和既有 v1/v2 路由注册。转换使用现有研究记录、资产、草稿和插入意图表，没有另建一套产物存储。

一并修复 `writing_agent/api.py` 中事实使用情况查询引用不存在的 `dependencies.downstream_id` 的问题；现在按当前正文的 `revision_id` 查询，识别原有事实关联与互通产生的 `knowledge:fact` 关联。

## 验收与证据

新增 `tests/test_product_interop.py` 共 14 项业务测试，包含真实内容消费、跨项目隔离、旧版本拦截、重复转换、完整包关系、原件权限、来源失效传播、事实与写作联动、原生表格和历史版本固定。

`tests/serve_product_interop_fixture.py` 创建独立合成项目。`tests/product-interop-browser.cjs` 验证 10 条页面流程：总结预览、转随记、草稿采用、写作章节转交、共享资产、模型实际接收、图像插入、原生表格插入、统计发现和窄屏布局。浏览器结果无页面异常、无失败 API 请求。桌面分辨率 1440×1050，窄屏宽度 430 像素。

本机证据保存在 `.runtime/product-interop-20261102/`，包括 `browser-results.json`、`products-desktop.png`、`products-mobile.png`、`interop-final.xml` 与 `regression-final.xml`。这些是本地验收材料，按仓库原有规则不进入公开源码。

最终 188 项相关回归测试全部通过，14 项互通专项测试全部通过，10 条浏览器流程全部通过。前端 TypeScript 检查与生产构建通过；原有功能回归覆盖总结、文献更新、知识、研究助手、写作和图表，前序验证还覆盖导出和接口。模型流程使用合成响应验证实际请求内容，没有调用真实付费接口。测试使用临时或独立数据库，没有打开用户论文数据库。

源码与前端构建已更新。已有后端进程需要重启才能加载新增接口；桌面安装包和 ZIP 便携发行包没有在本次重新打包。
