# 0.3.2 资料概括与分点

资料中心现在可以在本地文字提取和 OCR 完成后，调用 DeepSeek 对资料生成整体概括、核心要点和主题归纳。支持 PPTX、PDF、DOCX 等已解析资料。

## 使用方法

1. 在“资料中心”或“接口与设置”展开“DeepSeek 资料总结设置”。
2. 填写 x5m5x 的 API key 并保存。接口固定为 `https://api.x5m5x.com`；默认模型 ID 为 `deepseek-chat`。
3. 点击“查询 DeepSeek 模型”，从服务商实际返回的列表选择可用的 DeepSeek 模型 ID，再保存。默认 ID 是否可用需要该账户实际验证。
4. 打开资料，点击“生成概括与分点”；或者在资料中心点击“DeepSeek 批量总结”。已有有效总结直接读取缓存。
5. 在“核心要点”和“主题归纳”中点击页码，查看对应原文。资料修改后会标记旧版总结，可点击“更新总结”。

## 模型与密钥

- 资料总结使用独立的 OpenAI 兼容 Chat Completions 请求，只允许 DeepSeek 模型。不会回退到全局模型。
- 该功能的密钥单独通过 Windows DPAPI 加密保存到数据目录的 `material-summary.dpapi`，设置接口只返回脱敏状态。也支持 `PAPER_SUMMARY_API_KEY` 环境变量。
- 全局模型与资料总结配置互相独立；资料总结不会把全局接口的密钥发送到 x5m5x。
- 只发送该任务使用的提取文字及讲者备注，原始 PPT 文件保留在本机。正文、备注、OCR 和中间摘要均按不可信资料处理，其中的指令不作为系统指令执行。

## 结果与费用控制

- 长资料按文字量分段总结，再分组归纳为全篇摘要，不静默截断后半部分。
- 成功片段单独缓存，重试可复用。保存总结时核对内容指纹，内容在生成过程中变化会阻止旧结果发布。
- 所有分点必须引用本次输入中存在的页码；空白或没有可提取文字的页面会明确列出。页码存在性校验不能代替语义核对。
- 总结保留为需人工核对的 AI 整理结果，不会自动确认论文规则或研究事实。
- 尊重“仅限本地”及派生资料的来源权限，发送前重新检查；沿用项目预算、用量与费用记录。
- 默认每次请求预算预留为 2（本地控制参数，沿用现有预算约定，不代表 DeepSeek 的实际单价）。未配置单价时费用保持未知；批量或分段任务可能因剩余项目预算不足而停止。
- 超时或远端执行状态未知不会自动重试，避免反复提交可能已计费的请求。已经收到但结构无效的响应会作为任务原始候选保留。

- 浏览器验收覆盖总结展示、页码跳转、缺失密钥提示、设置入口及移动端布局，截图来自隔离的合成资料。
