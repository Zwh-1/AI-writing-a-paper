# V2.0 目标缺口审计与本轮补齐记录

审计日期：2026-10-21。对应程序：0.2.0。对照文件：论文写作系统详细实现方案 V2.0。

## 1. 对上一版交付的纠正

0.1.0 是基础流程实现。67项测试和15项浏览器检查覆盖已有能力，不能作为V2.0全部目标完成的证明。先前交付没有逐项说明的实际缺口包括：

- 规则大多只能显示并人工核对，确定性检查主要为文献数量。
- “部分接受”仅把候选追加到末尾，缺少原位置替换和逐段差异。
- 提纲没有完整层级管理、安全归档与循环依赖检查。
- 原有语义核查没有形成可失效的、按章节签署的人工规则核对记录。
- 排版参数没有与生效规则联动；排版方案保存与切换界面未接通。
- 本地OCR缺失，图片识别依赖远端API或人工转录。
- 写作没有实际加载示例库；资料单元分类不能覆盖混合用途课件。
- 导出缺少统一读取事务和生成后DOCX属性核对；Markdown损失表格与公式。
- 缺少可运行的检索评测入口，以及展示真实交付缺口的项目状态页。

这些属于程序缺口，不能归咎于用户没有提供API key，也不能仅通过修改说明文档解决。

## 2. 本轮已落地的补齐项

| 项目 | 实际改动 | 验证方式 |
| --- | --- | --- |
| 可执行规则 | 字数上下限/范围、文献数量、近年比例、语种比例、必需章节/词项、禁用词项、标题/图/表数量和排版参数；实际页数保留人工核对 | `tests/test_completion.py` |
| 条件与操作范围 | 全文/章节规则、论文类型/操作/语言条件，白名单条件表达式 | 范围条件、非法表达式测试 |
| 规则参数候选 | 从明确条款推断字数、字体字号、边距等值，保留候选与来源 | 中文数字、厘米换算、小四字号回归测试 |
| AI结构化整理 | 逐条验证source_id和原文摘录，候选不自动确认，受外发策略和预算约束 | 合法与伪造原文的模型模拟测试 |
| 本地OCR | 使用Windows.Media.Ocr与已安装语言，不发送资料到网络；单页/文件批量任务，结果保留待核对 | 真实中文图片OCR测试、API线程能力测试 |
| 混合资料分类 | 每个来源单元可分类为规则、研究证据、正例、反例或点评；检索按单元用途筛选 | 反例排除与示例召回测试 |
| 提纲管理 | 层级、顺序、多个依赖、目标字数；版本冲突、父链和依赖循环检查 | 后端与浏览器测试 |
| 章节归档恢复 | 保留正文与版本；存在子章节/依赖时阻止归档；恢复后进入活动提纲 | 可恢复归档测试 |
| 定向改写 | 当前或连续选中段落作为写作范围，其余正文不替换 | 实际请求范围和保留段落测试 |
| 候选差异与替换 | 计算逐段差异，可选原文与候选在原位置替换；追加仍为明确的独立操作 | 替换结果和版本冲突测试 |
| 人工核对 | 核对结果绑定规则包、当前章节和项目输入指纹；材料或正文变化后失效 | 版本失效、跨章节不扩散测试 |
| 章节审阅 | 明确记录用户已审阅的当前正文版本，保留记录，不能用旧版本签署 | 当前版本保护测试 |
| 规则和排版联动 | 预览生效强制排版条款差异，确认后应用配置 | 字号规则应用测试 |
| 排版方案 | 保存格式和模板快照、切换、记录真实人工验收说明 | 方案切换和项目隔离测试 |
| 一致性快照导出 | 同一读事务固定项目、正文、规则、引用、事实和资料版本 | 快照与书目版本测试 |
| DOCX检查 | 核对生成文件的A4尺寸、边距、字体、字号、行距与字符缩进 | 实际生成DOCX的属性测试 |
| 结构化Markdown | 输出标题层级、普通表格、列表、公式、引用和图像资源 | Markdown和资源测试 |
| 准备状态和影响 | 逐项展示规则覆盖、正文、人工审阅、过期章节和检查结果 | API与浏览器测试 |
| 检索评测 | 用户提交问题与标准来源，计算并保存Recall@10逐条结果 | 评测标注验证和实际召回测试 |
| 已知限流恢复 | 仅对明确429拒绝进行可取消的有界退避；未知结果不自动重发，每次尝试留记录 | 限流和未知结果模拟测试 |

## 4. 明确保留的未完成目标

以下项目继续保留在总目标中，不因升级为0.2.0就转为“已完成”。

### 需要真实输入才能验收

- 真实API key、实际Gemini模型ID、协议、权限和计费口径。
- 对现有规范、图片OCR和规则冲突的用户确认；程序不会伪造这项审核。
- 实际论文题目、研究成果、实验或系统测试材料。
- 学校正式DOCX模板和指定软件中的版面验收。
- 至少30条人工确认的实际检索问题与来源标注。
- 一篇实际论文从准备到提交候选的完整人工验收。

### 仍需进一步开发

- 神经向量与关键词的混合检索、独立召回重排评测。
- PPT整页的本地版式还原、复杂对象与跨页表格理解。
- 高级统计方案、受控测试/代码执行、自动实际系统截图采集。
- 复杂公式、脚注、文献作者年份样式和复杂封面分节的无损编辑/排版。
- 服务方支持时的真实Token流式预览和更细粒度输出恢复。
- 多用户权限、实时协作、远程部署、云同步和跨设备冲突处理。

这些属于明确剩余开发工作。当前版本以本地单用户使用为基础，不以“接口已预留”代替功能实现。

## 5. 数据与升级

数据库从v1增量升级到v2，只增加表。首次升级前保存 `data/migration-v1-before-v2.sqlite3`，原始资料、正文、引用和规则包保留。正式运行目录与自动测试目录分离。

当前资料的核对、确认和规则包发布仍由用户决定。新OCR候选不会自动标为已审核；新执行规则不会改变已发布规则包，需重新发布后生效。
