# 0.7.0 图谱与 Wiki 知识库

本功能在“文献与术语 → 图谱与 Wiki”。原文、论断、图谱和 Wiki 共用稳定来源；知识页面及模型判断不自动成为经过核验的论文事实。

## 开始使用

1. 导入原件，完成现有结构解析。在“构建与更新”选择研究文献、写作指导或项目实现范围。
2. 选择“本地原文摘录”预览并构建。它不调用远端模型，建立可定位的原文观察、摘录关系和文献页面，不代表完成语义综合。
3. 要提取方法、对象、条件、指标和语义关系，选择“AI 编译”。先看请求数量与预算；一份长文献会有多次请求，不能把31份文献理解成31次调用。
4. 在“关系探索”检索问题，选择论断，生成主题、比较或分歧页候选。条件、否定、数据集、比较对象和结论强度应随论断保留；未知字段不补造。
5. 查看候选、来源和差异，再发布 Wiki 修订。页面发布表示版本进入知识视图，不表示所有论断已人工核验。
6. 在“章节准备”执行阅读计划；实际读取的原文范围进入问题阅读记录。打开“用于章节写作”后，普通写作和有据写作接入同一知识层，仍保留已保存论文全文、强制规则和原文支持性核验。

## 图谱、消歧与支持性

- 默认实体在资料范围内识别；人工术语表和人工归并用于建立明确的跨资料对应，不能凭同名自动认作同一事物。
- 归并前比较实体及来源；拆分可以把所选论断绑定到新实体，保留原版本和原始证据，不复制旧的人工支持性结论。
- 关系路径只表示可探索的关联，不能直接推出因果或论断成立。
- 人工核对需要具体引句、核对人、理由及原件对照；模型检查单独记录。
- 代码观察、测试定义、实际测试执行、部署、作者声明及登记结果分别保存。文献或课件示例不能当成本项目实测。
- 原文确认、作者编辑、模型评估、人工支持性和版本有效性是不同状态。

## Wiki 维护

页面支持文献、概念、方法、主题、比较、分歧、项目及指导类型，按完整块保存出处。

人工备注在自动更新时保留。来源失效后可以先保存修订候选；保留旧来源的块会提示重新关联，未解决前不能发布为当前有效版本。编辑器可检索当前论断、清除旧来源、添加新来源或移除块；旧版本继续可读。

“检查与版本”提供确定性断链/过期检查，以及有界的模型语义疑点检查。模型疑点只是回读线索，不是证明文献错误或结论矛盾。

资料变更默认只触发本地更新。选择 AI 自动更新后仍受预算限制，并为受影响的主题等页面准备更新候选；不会直接覆盖人工编辑或论文正文。

来源、用途和外发权限改变后，派生页面、图谱及模型缓存重新校验。在综合文字中删除一个引用编号不能解除其来源限制。

## 微软 GraphRAG 组件

原生图谱与 Wiki 可以独立使用。微软计算后端固定为3.3.0，运行在独立目录，主程序不混装其依赖。

需要时安装同版本“知识图谱计算组件”ZIP。主程序和组件分开发行；组件约需额外近0.9GB解压空间，具体大小以包清单为准。

在 **PowerShell 7.6.5 Core 的 pwsh.exe** 中先核验，再执行安装：

```powershell
if ($PSVersionTable.PSVersion.ToString() -cne '7.6.5' -or $PSVersionTable.PSEdition -cne 'Core') { throw 'Required PowerShell 7.6.5 Core' }
./安装便携组件.ps1 -PackagePath 'D:/你的目录/砚台论文工作台_0.7.0_知识图谱计算组件.zip'
```

可以先加 `-VerifyOnly` 仅校验组件。安装器核验版本、文件哈希和目标目录，不覆盖用户数据。

构建时可以选完整范围或问题附近的局部范围；局部范围不会宣称覆盖全库。完整范围超过上限时明确拒绝，不截断后标成完成。

Global 需要社区报告；Local 和 DRIFT 还需要该索引的真实本地向量。向量模型或输入格式改变后需重建，不能混用不同空间。

社区结构、社区报告、嵌入和三种查询能力分别记录。索引中断保留部分产物和来源映射，可以按原输入和配置续建；部分索引不能冒充完整查询。输出以完整响应适配 SDK 分块接口，不宣称上游提供了实时 SSE。

## 费用、失败和恢复

费用显示采用当前接口币种，所有远端抽取、检查、综合、社区和查询调用进入原任务账本。

相同输入的已知完成响应可以复用；并发相同请求会串行等待，读取缓存前仍检查来源权限。

能确认建立 HTTP 连接前失败的请求按发送前失败记录。读取/写入阶段超时、HTTP 524 等远端执行不明的情况继续保留未知状态及费用预留，不自动重发。

核对远端执行和账单后，如仍决定重试，可以勾选“已核对远端记录，知悉重试可能再次计费”，再续接原任务或索引。该选择不等于免除原预留，项目和任务预算仍生效。

模型引句不能定位时不采纳其支持性结论。格式整理只允许围栏/安全字面量等语法规范化，不执行模型代码、不猜测缺失字段，也不改写事实值；原输出及处理记录保留。

## 评测与真实验收

80个预置任务是待编辑草稿，不能当作已完成金标准。填写真实问题、可接受原文或项目证据和核对人后，再运行 A/B/C/D 对照。

对照可选择只检索，或在预算内生成四组回答。盲审视图隐藏组合名称；人工支持数、限定条件、误引和扩写计数单独记录，之后可以揭示组合。

自动召回、模型自评、回归测试和页面数量都不能替代人工语义验收。当前没有自动填入真实资料的人工金标准、支持性结论或95%准确率。

## 导出、升级与回退

知识库可以导出 Markdown、来源映射和历史记录。论文导出附带与正文同一读取快照的知识使用追溯。

完整本地备份包含新表与必要原件；发行包不包含论文、API密钥和本机测试数据。旧的正文同步协议继续拒绝不完整的知识传输，完整知识云同步不属于本版已交付能力。

旧程序不能直接打开新数据库。回退知识行为应关闭写作知识开关或切换知识发布版本，保留升级后新增正文；不要用旧整库备份覆盖后来的论文。

## 内容状态与验收边界

发行包只含程序和公共运行组件，不预置用户论文、研究原件或知识库；请导入自己的资料或使用完整本地备份。

本地构建不代表全量 AI 语义编译完成，也不代表主题、比较和分歧已成为可信综述。页面可以包含原文摘录、索引、项目记录和待审模型候选，界面分别标记。

当前工程已对真实模型和部分微软查询取得响应，但 DRIFT 的当前接口验收受上游超时阻断，不用其他查询结果替代。具体测试、内容构建和剩余工作保存在本机交付报告，不随公共安装包分发。
