# 0.7.3 完整整合便携版

本次发布文件为 **砚台论文工作台_0.7.3_完整整合便携版.zip**。知识图谱和其他功能位于同一个 ZIP 中，无须另外下载、解压或安装知识图谱组件包。

## 包内内容

- 完整工作台及六页文献工作台布局优化。
- Python、Node、业务依赖和 PowerShell 7.6.5 Core。
- GraphRAG 3.3.0 及其锁定运行依赖；图谱、Wiki、查询、核对、维护和迁移入口均在同一工作台中。
- 配套 Chromium headless shell 截图浏览器。
- BGE small 中文向量模型与 BGE reranker 本地重排模型，均保留校验清单。
- 原文解析、规则管理、写作、图表、统计、导出等原有业务功能。

图谱计算依赖在程序内部按其需要的环境加载，用户不需要手工拆包、安装依赖或切换程序。当前整合 ZIP 约 **984.2 MB（938.6 MiB）**；请在 ZIP 旁的 `.zip.sha256` 文件查看本次发行的准确校验值。整合包包含模型和浏览器，因此不沿用历史精简包的 500 MB 体积目标。

## 启动

1. 将整个 ZIP 解压到一个新目录。先完整解压，再运行程序。
2. 双击根目录中的 `启动工作台.cmd`。
3. 浏览器打开后，在工作台中创建或导入项目。
4. 退出时双击 `停止工作台.cmd`。

本地解析、检索、图谱和 Wiki 浏览使用包内运行资源，不需要首次下载浏览器或上述两个默认模型。AI 写作、模型综合、社区报告、生图等收费能力仍需要用户配置自己的接口、密钥和预算。

发行包不包含个人论文、项目数据库、服务会话或 API 密钥。迁移已有项目时，从旧工作台创建备份，再在新目录的工作台中恢复；已有数据目录不要用发行包中的文件覆盖。Windows OCR 语言和需要精确 Office 渲染或容器执行的系统能力仍由使用环境提供。

## 开发打包与验收

默认 CLI 打包方式为 `integrated`，生成一个 ZIP，内含主程序、图谱运行库、浏览器和模型：

```powershell
if ($PSVersionTable.PSVersion.ToString() -cne '7.6.5' -or $PSVersionTable.PSEdition -cne 'Core') { throw 'Required PowerShell 7.6.5 Core.' }
& './.runtime/python/python.exe' -I -X utf8 './scripts/package.py' --profile integrated
```

打包前要求前端、后端及 lockfile 版本一致；最终包内 26,411 个文件的 SHA256 在写入后逐项复核。同目录的 `.zip.sha256` 文件可用于校验发行 ZIP。

发行验收从最终性能修复 ZIP 解压完成，使用包内运行时验证本地浏览器截图、向量检索与交叉重排、图表预览、可编辑 Word 表格、PDF 导出和统计功能。GraphRAG 3.3.0 的同步/异步协议通过验证，并在无网络、无付费模型调用的情况下实际生成合成原文关系的社区索引。六个文献工作台在解压后的程序中完成桌面和 390px 窄屏检查。

验收报告位于工作目录 `docs/v0.7.3-package-verification.json`；解压运行、图谱和浏览器报告及六页截图位于 `.runtime/release-v073-qa/`。

历史的精简、离线及组件 profile 仅作为兼容的开发选项保留，本次交付不输出拆分组件包。
