# 0.2.2余额接口与验收测试说明

日期：2026年10月21日。本补丁增加用户提供的/v1/usage余额查询，并对五项实际验收准备进行了测试。实际项目回执保存在用户数据目录，便携包不包含这些数据、账户余额、源文件或密钥。

## 本次功能

- 设置页显示整个中转站账户的余额、状态、查询时间；主动点击查询，不产生模型生成请求。
- 后端按Bearer调用/v1/usage，保留0和false；无法解析的余额不当作0。失败时保留上次回执，更换密钥或地址清除余额缓存，归一化历史最多30条。
- 修复保存后的旧设置响应覆盖新余额的时序问题；延迟响应回归验证刷新结果不会倒退。
- 模型检测、保存密钥、脱敏提示和失败保留输入的0.2.1修复仍保留。
- 检索评测分别显示命中与平均召回；多个正确来源只找回部分时按实际比例计数。提交来源ID不自动等于人工确认。
- scripts/acceptance_check.py默认执行本地隔离副本测试。显式添加--live-probe才对已配置的中转站发出一个短模型请求；它会按服务商规则计费，结果不明时不自动重试。

## 验证

后端138项测试通过。浏览器基础15、功能8、设置和余额17，共40项通过。TypeScript与生产构建成功。归一化账户回执只存金额、单位、状态、地址和时间等所需字段，不保存原始接口body或请求头。

实际资料上制作了32条待人工确认的检索样本，初步命中28条；3页OCR抽样发现确有错字，保持未审核。演练DOCX的11项属性检查、独立PDF预览、备份恢复流程完成。学校模板、用户研究材料、人工金标和一篇真实论文的人工验收仍需补齐。

实际模型列表成功不代表生成成功。本轮使用配置的Gemini 4 ID测试三个协议，均被中转站拒绝；明确回执为当前分组没有配置支持该模型的上游账号。未将固定演练样本记为真实生成通过，未修改用户保存的模型或协议。

## 边界

账户余额不等于项目花费；余额差异不能单独证明一次请求的账单；未配置价格的调用仍保留费用未知。独立PDF不证明Word分页合格；自动化操作不代表用户审核；规则候选、OCR候选与检索候选均需实际确认。0.2.2不代表V2.0全部目标完成。
