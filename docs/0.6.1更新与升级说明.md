# 0.6.1 更新与升级说明

发布日期：2026-10-26。应用版本：0.6.1。数据库版本：9。

本版集成当前文献阅读、证据知识库与写作修复，保留现有资料、书目及引用编号。文献检索用于定位原件，普通写作读取完整解析文本或按具体问题读取相关范围；超出预算时保留缺口。阅读覆盖、候选判断、人工阅读核对与具体论断支持性分别记录。

“文献与术语 → 文献与资料阅读”提供研究文献、写作资料与示例两个入口。同一原件可以同时用于研究引用及写作示例；课件正反例、范文及评分条件不能作为本项目成果证据。阅读范围和用途改变后，引用提示重新核对。完整实现及验收边界见 [文献阅读与用途修复](0.6.1文献阅读与用途修复.md)。

本版同时包含当前工作区已经接入的写作启动与预算整理、章节衔接、独立润写、论文图表、配图规范和独立图片接口功能；接口需要使用者自己的配置，计费操作仍由使用者发起。

## 便携包

文件名：`砚台论文工作台_0.6.1_便携版.zip`。

包含应用源码、构建后的前端、数据库迁移、提示词、说明文档、测试及本机已准备的便携运行组件和本地检索模型。包内“便携包清单.json”登记每个文件的 SHA-256，打包脚本逐文件校验。

包中不包含用户数据库、论文原件、已写正文、API 密钥、浏览器用户目录或私人实测输出。既有用户数据继续保存在各自的数据目录；31 篇文献恢复研究用途是原机器的数据修复结果，发行包不携带这些文献。

## 升级

1. 等待正在运行的写作、解析及图片任务结束，使用 PowerShell **7.6.5 Core** 执行旧版的 `停止论文工作台.ps1`。
2. 先备份旧版 `data` 目录。将新版程序解压到独立目录；需要继续使用既有论文时，将旧版 `data` 目录复制到新版目录下，保留旧副本。
3. 使用 PowerShell **7.6.5 Core** 执行新版 `启动论文工作台.ps1`。首次启动自动升级数据库，升级前备份保存在数据目录的 `migration-before-writing-v9.sqlite3`。
4. 打开资料、书目和已有章节核对升级结果。阅读与引用仍需逐项核对；程序不会把既有原文自动登记为人工语义审核通过。

升级至数据库版本 9 后，不要用旧程序打开升级后的数据。需要回退时，停止新版，使用旧程序和升级前数据副本。

Windows DPAPI 加密的接口密钥不能直接跨 Windows 账户迁移；换电脑或账户后请重新填写。旧版云同步不能完整传输新版证据对象，已有明确阻止提示，请使用完整本地备份及隔离恢复。
