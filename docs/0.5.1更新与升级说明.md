# 砚台 · 论文工作台 0.5.1

发布日期：2026-10-25。应用版本从 0.5.0 更新为 0.5.1，前端、后端、锁文件和便携包使用同一版本号。

## 本次更新

- **直接开始本节写作**：入口自动匹配当前模型配置，必要时建立项目基线；发送前检查章节、项目状态、资料权限、版本、上下文和费用预留。未满足条件时显示具体原因。
- **按章节整理输入**：完整载入适用的强制规则，按主题检索建议条款，保留完整证据片段、书目信息和引用位置。OCR 坐标和重复识别数据留在本机；未读原文只作为目录，不能充当论据。
- **各阶段独立检查额度**：调查、判定、正文生成、逐句关联、语义及衔接检查分别检查输入规模与输出额度，不必仅为启动写作而提高全局上下文。必要材料仍不能容纳时，发送前明确停止。
- **费用与恢复**：未知单价时使用严格匹配的账单区间核对；无法匹配的预留继续保留。已完整返回的同一冻结请求可在本机重新解析，避免为格式适配再次请求。
- **候选审阅入口**：生成后显示候选状态与直达入口，刷新后可恢复。阶段附注可折叠，手机布局减少横向溢出；同一章节存在活动会话时阻止重复启动。
- **页面更新**：HTML 禁用旧页面缓存，重新打开时读取当前构建；保留资料与规则工作区的现有交互改进。

## 升级与数据

继续使用原工作目录即可保留已有项目、正文、来源、预算和费用记录。数据库版本仍为 7，本次升级不重置项目数据，不自动提高预算，也不自动将候选采用到正文。

便携包包含应用源码、构建后的前端、Python、本地依赖和已安装的公共检索模型。包内不含用户项目数据库、论文原件、候选导出、API 密钥、登录态或私人实测输出。解压到新目录会使用独立数据目录；继续原项目时使用原工作目录，或通过工作台的完整备份恢复。

启动要求 PowerShell 7.6.5 Core。停止旧服务后重新运行 `启动论文工作台.ps1`。

## 验证与边界

本次写作修复已通过后端回归、前端生产构建和独立浏览器流程检查，并在实际项目用配置的主模型完成调查、判定、生成与后续核验，产出章节候选。真实候选仍有待处理的核验项，处于待审阅状态；阶段完成不等于内容全部通过，程序不会自动填入人工确认。

费用、候选、项目标识和截图等私人验证材料保存在原机器，不随便携包发布。详细实现与检查范围见 [有据写作入口与启动检查修复](有据写作入口与启动检查修复.md)。
