# GPT 生图独立接口配置

2026-10-26 接入。论文图片生成和图片编辑固定使用 `gpt-image-2`，专用中转地址为 `https://api.hanhegufei.online`。程序通过 `/v1/images/generations` 生成图片，通过 `/v1/images/edits` 编辑图片；地址末尾是否带 `/v1` 均可，程序不会重复追加。

## 配置入口

打开“接口与设置 → GPT 生图专用设置”，或在“论文图表 → GPT 图片生成与修改”中展开“gpt-image-2 专用接口与独立 key”。

填写此中转站的独立生图 key，选择图片尺寸与画质，点击“保存生图设置”。保存设置本身不发起生图请求。默认横图为 2048 × 1152，另有竖图、方图与标准尺寸可选；接口实际返回的宽高会单独记录，不会通过放大小图伪装成高分辨率。

生图密钥单独保存在当前数据目录的 `image-generation.dpapi`，使用当前 Windows 用户的 DPAPI 加密；环境变量入口为 `PAPER_IMAGE_API_KEY`。读取生图设置只返回掩码。留空保存配置保留原 key，“清除独立生图 key”只操作这一份凭据。正文主模型、GPT 文字备选与资料总结各自保留原来的配置和密钥。

## 使用流程

1. 在写作工作台保存正文，再打开“论文图表”；也可从“研究与成果”选择已保存章节。
2. 选择流程、用例、ER、架构、模块、类、时序、数据流、结构、合约交互或电路设计图，填写图片标题和具体要求。
3. 选择“图片紧随此段落插入”，填写图后说明、必需文字与禁止内容。先点击“预览生成提示词（免费）”，核对范围与完整提示词，再点击“使用 gpt-image-2 生成（计费）”。代码示例不会默认进入新生图；需要采用实际结构时勾选“生成时采用当前结构蓝图”。
4. 继续修改时填写要求，先预览修改提示词，再点击“使用 gpt-image-2 修改（计费）”。程序发送当前图片作为编辑参考，保留原约束并另存新图片。旧正文版本只用于溯源，不与当前段落混合作图。
5. 生成后逐项核对图片中的中文、元素、连线和分支与目标段落、图后说明是否一致，勾选确认并填写具体依据，再插入正文。程序按绑定段落定位，不随光标移动；正文或参考章节变化会阻止旧候选插入。独立候选及旧图须显式选择位置核对。
6. 生成的图片可下载 PNG，生图记录可下载 JSON。图片仍使用现有的 Word 插图和整篇交付流程。详细边界见《生图提示词与段落语义对齐_2026-10-26.md》。

图片默认是待核对的设计草图。插入前填写图后说明，并按本项目规范确认 AI 图片政策。原始／实验结果、界面截图和测试日志请上传实际产物；生图模型不能替代它们。研究方法例外须在正文记录 AI 方法并关联代码、数据或执行材料。

代码预览仍可在本机直接绘制。三线表使用结构化数据和原生 Word 单元格，生成可编辑表格的 AI 辅助使用文字模型。

## 费用与异常

生图请求使用独立 key 的账户，项目内单独记录模型、地址、凭据指纹、原始用量和费用预留。中转站若按张固定收费，可填写单张金额；按 Token 等方式计费或价格不明确时保持为空，费用继续按未知预留记录。币种必须与项目预算一致。

每次任务只发送一次图片请求。超时或服务端结果不明时保留预留，重试需要明确知悉可能再次计费。请求成功但图片格式无效也保留可能已计费的记录，不自动切换到其他图片模型、正文模型或文字备选 key。

本次验收使用隔离项目、模拟 HTTP 图片接口及模拟 PNG，验证了生成、编辑、独立凭据、预算、错误状态和正文插入。真实中转站出图需要用户在程序中填写独立 key 后验证；验收未调用用户的付费生图接口。
