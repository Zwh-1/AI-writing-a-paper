# 1.0.0 完整整合便携版使用说明

发行文件为 `砚台论文工作台_1.0.0_完整整合便携版.zip`。本版可以支撑一篇真实论文从资料准备、写作、审阅到导出的完整流程。内容质量、参考文献准确性及学校要求的目录、页眉、图表和全文格式仍须逐项复核和继续优化；程序检查不能代替人工学术审阅或学校终审。

## 安装与升级

1. 将 ZIP 完整解压到一个新的目录，不要直接在压缩包内运行。
2. 双击根目录的 `启动工作台.cmd`，在“接口与设置”中配置自己的模型地址、密钥和预算。AI 写作需要可用的模型服务；未配置时可使用本地研究、编辑和导出功能。
3. 用工作台的备份与恢复功能迁移已有项目。不要用新目录覆盖旧版的 `data`、数据库或用户资料。
4. 退出时双击 `停止工作台.cmd`。

包内集成 Python、Node、PowerShell 7.6.5 Core、截图浏览器、中文向量与重排模型，以及 GraphRAG 运行库；无需首次下载这些公共组件。Windows OCR 语言包、Office 渲染和 Docker 执行等能力依宿主环境而定。

## 交付与校验

发行包不应包含用户论文、项目数据库、会话、API 密钥或登录态。请先核对 ZIP 旁的 SHA256 文件，再查看包内 `便携包清单.json`：版本应为 `1.0.0`、配置为 `integrated`、源码工作区状态为干净，并有逐文件 SHA256。论文导出的 Word、PDF 和整包仍须按具体模板逐页检查引用、目录层级、页眉及图表。
