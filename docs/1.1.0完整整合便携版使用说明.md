# 1.1.0 完整整合便携版使用说明

发布日期：2026-11-08。

## 更新内容

完善了项目langchain层

本版整合当前智能体、长期记忆、上下文管理和技能实现，并修复任务恢复、配置快照、冲突记忆、技能预算及图表生成的一致性问题。详细问题、优先级、改动影响与验证范围见[模块审查报告](模块一致性全面审查与优化_2026-11-08.md)。MCP 诊断会明确报告尚未实现外部协议连接，不能将宿主工具封装视为已接入 MCP 服务。

## 安装与升级

1. 校验 ZIP 旁的 SHA256 文件，将 `砚台论文工作台_1.1.0_完整整合便携版.zip` 完整解压到新目录，不要在压缩包内启动。
2. 从旧版迁移前，等待在途任务结束并备份项目；通过旧版的 `停止工作台.cmd` 停止实例，再使用备份与恢复功能迁移。不要将新程序覆盖到旧版的 `data`、数据库或用户资料中。
3. 双击新目录内的 `启动工作台.cmd`，在“接口与设置”中配置自己的模型地址、密钥和预算。AI 写作需要可用的模型服务；本地研究、编辑及导出功能仍可独立使用。
4. 结束使用时双击新目录内的 `停止工作台.cmd`。通过设置中的运行诊断确认前端、API 和执行器实际加载的版本为 1.1.0；只替换磁盘源码不会升级已运行的旧实例。

包内集成 Python、Node、PowerShell 7.6.5 Core、截图浏览器、中文向量与重排模型，以及 LangChain、LangGraph 和 GraphRAG 所需运行库，无需首次下载这些公共组件。Windows OCR 语言包、Office 渲染及 Docker 执行能力仍依赖宿主环境。

## 制品校验

ZIP 包内的 `便携包清单.json` 应显示版本 `1.1.0`、配置 `integrated`、`source_dirty=false`，并记录实际 Git 提交及逐文件 SHA256。`build-info.json` 的版本、提交和构建标识应与便携包清单一致；前端内嵌的源码指纹应对应同一份源码。

发行包不包含用户论文、项目数据库、会话、API 密钥或登录态。程序测试、包完整性及隔离启动验证不能替代真实论文的学术审阅；引用、学校模板、Office 分页及图表可读性仍需按实际交付文件检查。

## 使用边界

- 新对话任务发现智能体配置变化时返回 409，应使用当前配置重新提交；旧写作会话继续使用冻结的协议、记忆和技能版本，来源权限撤回仍优先。
- 冲突作者决定无法完整装入上下文时会整组延后，不会只提供其中一方；技能预算包含实际宿主包装文字，临界配置可能需要提高预算或减少显式选择。
- 检查点恢复遇到同键不同内容时拒绝恢复并返回 409，不会覆盖现有状态；图表度量为 unknown 表示尚无充分的检查依据。
