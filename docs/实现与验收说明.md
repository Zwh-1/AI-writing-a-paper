# 实现与验收说明

> 本文件原为0.1.0验收范围记录。0.2.0的补齐情况与仍未完成目标，以《V2.0目标缺口审计与补齐记录.md》和对应测试报告为准；请勿使用旧限制说明判断当前OCR、规则检查或部分替换能力。

日期：2026-10-20。版本：0.1.0。本文件区分已实现程序能力、待用户确认的资料和尚未完成的扩展范围。

## 功能对应

| 原设计需求 | 当前实现 | 验证/限制 |
| --- | --- | --- |
| 研究简报与范围 | 项目字段、研究问题、目标、方法、作者信息、版本 | 自动保存与项目修订测试；研究内容由用户提供 |
| 规则适用与冲突 | 类别、全文/章节范围、性质、决策、数值冲突、包快照 | 强制冲突与未核对来源阻止发布 |
| 写作前加载规则 | 每次请求的应加载/实际加载 ID、规则文本哈希与请求哈希 | 模拟模型契约验证；实际中转站需填密钥 |
| PPT 与图片 | 按关系映射页序，文字、表格、图片、备注，PDF 原页 | 25 文件实际导入；PPT 整页版式未重建 |
| 正反例分开 | 文件用途、条款性质、反例候选 | 自动分类是候选，需要人工核对 |
| 实际成果 | 计划/实现/测量、核查状态、来源与产物 | 用户声明与实际分析分别记录 |
| 问题与证据 | 段落 sourceIds/factIds、引用与依赖、研究覆盖表 | 跨项目来源拒绝；不自动证明研究贡献 |
| 提纲和目标 | 类型模板、AI 候选、章节目标、字数和依赖 | 候选可编辑追加；已有正文不会静默清空 |
| 写作顺序 | 逐节与批量候选、摘要后置、相关章节上下文 | 后续内容过期提示；候选不自动审核 |
| 检索 | 中文分词、术语同义词扩展、全文搜索、来源过滤 | 中文样本通过；未完成30条人工金标召回评测 |
| 引用 | 书目、元数据候选、引用节点、原文核查、快照与统一编号 | 数量按正文已引用去重计算；多样式和复杂引注待扩展 |
| 数据与图表 | CSV/XLSX、实际描述统计、分布图、原件与参数 | 不执行任意生成代码；高级统计未包含 |
| 全文一致性 | 显式依赖、事实变更提示、术语、摘要、AI 语义检查 | AI 结果保留待判断；不能保证发现全部矛盾 |
| 人工编辑 | 自动保存、应急草稿、版本冲突、锁定、候选比较和部分接受 | 后端与浏览器验证；部分接受采用追加语义 |
| 文风与翻译 | 定向指令、术语表、翻译操作、摘要过期提示 | 真实生成质量待实际模型验证 |
| 排版交付 | DOCX、Markdown、独立 PDF、报告、清单与交付 ZIP | Word 视觉验收、复杂模板和复杂公式待专项处理 |
| 任务和费用 | 独立 worker、事件、取消、恢复、未知结果、预算、人工结算 | 不保证撤销远端已执行请求；没有真实账单样本 |
| 权限与隔离 | DPAPI、本机会话、Origin/CSRF、原件与派生内容发送前复核 | 本地单用户模型；不作为多租户服务部署 |
| 保存与备份 | 不可变原件/正文/规则包、SQLite 一致性备份、哈希恢复 | 在隔离目录验证；凭据不入备份 |
| 测试 | 后端业务、协议模拟、浏览器完整流程、实际资料与导出样本 | 结果由生成的测试报告记录，不把模拟服务算作真实API验收 |

## 需要用户完成的准备

1. API key、真实模型 ID、协议与实际计价口径。
2. 对规则来源逐页核对，确认条款与冲突，发布规则包。
3. 具体论文题目、研究资料、真实成果和学校最终格式。
4. 研究论证、引用含义与学校目标软件中的视觉验收。

以上为使用过程的必要输入，不代表程序已代替用户完成审核。

V2.0 中列为后续的团队协作、云端同步、通用模板适配、神经向量检索、本地 OCR 模型、高级统计与复杂公式排版，不能标记为完成。当前版本提供了独立服务模块、版本化数据和适配接口，方便后续扩展。
