# 从源码运行

源码面向 Windows。需要 PowerShell **7.6.5 Core**、Python **3.12 或更高版本**以及 Node.js/npm。启动和停止脚本严格校验 PowerShell 版本。

在仓库根目录安装后端依赖并构建前端：

```powershell
if ($PSVersionTable.PSVersion.ToString() -cne '7.6.5' -or $PSVersionTable.PSEdition -cne 'Core') {
    throw '必须使用 PowerShell 7.6.5 Core。'
}
python -m venv .venv
& '.\.venv\Scripts\python.exe' -m pip install -r requirements.lock.txt
npm ci --prefix frontend
npm run build --prefix frontend
$env:PAPER_PYTHON=(Resolve-Path '.\.venv\Scripts\python.exe').Path
& '.\启动论文工作台.ps1'
```

工作台默认监听本机 `127.0.0.1:8765`。在设置界面填写自己的模型接口及密钥；连接模型不属于依赖安装步骤，计费能力测试需由使用者明确执行。密钥采用 Windows DPAPI 保存，不能直接跨 Windows 账户复制使用。

停止服务：

```powershell
if ($PSVersionTable.PSVersion.ToString() -cne '7.6.5' -or $PSVersionTable.PSEdition -cne 'Core') {
    throw '必须使用 PowerShell 7.6.5 Core。'
}
& '.\停止论文工作台.ps1'
```

在同一 Python 环境执行后端测试：

```powershell
if ($PSVersionTable.PSVersion.ToString() -cne '7.6.5' -or $PSVersionTable.PSEdition -cne 'Core') {
    throw '必须使用 PowerShell 7.6.5 Core。'
}
& '.\.venv\Scripts\python.exe' -X utf8 '.\runner.py' test
```

`.runtime`、`.experimental`、`data`、虚拟环境、前端构建产物、原始实测记录和截图均不进入 Git。便携版需要另外准备 Python、依赖、前端及所需运行组件，不能仅凭源码目录认为已包含完整离线环境。高级功能的附加依赖位于 `requirements-advanced.lock.txt`；截图浏览器、神经检索模型、Office 渲染及容器执行按对应功能说明另行准备。

公共测试使用隔离数据和模拟接口。`scripts/writing-agent` 中的真实验收脚本依赖本机专门准备的授权配置、项目资料及实验账本，源码克隆后不应直接运行，也不会随仓库提供私人实测数据或密钥。
