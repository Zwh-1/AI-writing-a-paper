# 文献与术语

文献库支持 ZIP 文献包、BibTeX/RIS、手工书目和按需 Crossref 元数据查询。ZIP 导入在本地完成，识别书目与 PDF 原件，不自动启动付费 AI 总结或规则托管。

## ZIP 文献包

压缩包中应包含唯一的 `文献索引.csv`。必须有 `文件名`、`完整著录` 两列；可附 `论文编号`、`分类`、`年份`、`语种`、`页数`。分类和文件名组合定位 PDF，也支持唯一文件名匹配。预览会检查原件、页数、目录路径与重复记录，导入时再次核对文件哈希。

导入后：

- PDF 作为研究文献关联书目，原始 ZIP 留存于项目，可从导入记录下载。
- 原始完整著录、目录位置、分类和页数保留，书目信息保持待核对。
- 通过原件哈希、DOI 或题名去重，不覆盖已存在的人工书目信息。已有书目未关联原文时可补充关联，并保留修改历史。
- 先提取原生文字，供检索与原文查看。含图表或扫描内容的页面仍保留待核对状态，可在原文查看中继续识别、修复和核对。
- 文献原文同时登记为本地知识文档，片段可全文检索；本地模型就绪时自动增量建立向量索引。存储和检索流程见[文献知识库说明](文献知识库存储与检索.md)。
- 其他清单与说明保存在原始包中，不将历史清单的不同版本自动混入当前索引。

## 查看与核对

可按题名、作者、DOI 搜索，按分类、语种和书目核查状态筛选，并调整分页。点击“查看原文”打开对应 PDF，点击“核对书目”编辑字段、关联原件及记录核对范围。书目匹配、原文可用和正文论断获得支持分别处理，导入不等于引用支持性已通过。

列表中的序号仅用于库内浏览；正式引用序号按正文使用顺序计算，导出仍只收录实际引用的条目。未编辑的导入条目保留完整原始著录；编辑书目字段后，原始著录作为来源保留，导出使用更新后的字段。

术语表支持新增、编辑和删除。已登记的中英文译法供正文写作和中文摘要到英文摘要的翻译共用，不凭参考文献题名自动填入未核对的译法。

## 验证

针对压缩包校验、重复导入、原文关联、项目隔离、无付费副作用、原生解析、术语管理和既有写作功能执行了测试；真实文献库的搜索、筛选、分页、原件查看和响应式布局另经浏览器验证。私人导入记录、截图与数据库导入前副本保留于本机 `.runtime`，不进入源码仓库。
