# 文献知识库存储与检索

文献原文、书目信息、原页、知识片段和引用来源通过稳定编号关联，组成项目本地文献知识库。既有文献无需重新上传，已有引用来源编号继续有效。

| 内容 | 持久存储 | 用途 |
| --- | --- | --- |
| PDF 等原件 | 本机内容哈希对象库、`files` | 保留原件、版本及文件权限 |
| 书目 | `bibliography` | 保存题名、作者、年份、DOI及原件关联 |
| 原页及片段 | `pages`、`sources` | 保留原文、页码和来源编号 |
| 知识文档及片段登记 | `knowledge_documents`、`knowledge_chunks` | 关联项目、原件版本和片段内容哈希 |
| 全文索引 | SQLite FTS5 `source_fts` | 本地全文检索 |
| 向量索引 | `neural_vectors` | 保存带模型版本和文本哈希的真实本地向量 |

## 入库与更新

研究文献导入时登记知识文档，解析后将原文来源片段纳入知识库。后台解析任务会安排本地索引更新；同一项目正在排队或执行的索引任务合并处理。已完成的向量批次持久保存，后续更新只处理新增或内容变化的片段。

既有资料可点击“更新知识库”建立登记与索引。原件不重复复制，既有来源和引用编号不重新生成。新增表为可重建的知识库关联与索引层，完整本机数据库备份会包含这些数据。

当前安装的模型通过 FastEmbed / ONNX 在本机建立向量，向量命名空间包含模型文件版本与输入格式版本。模型未安装或索引暂未就绪时仍可使用全文检索；界面显示实际索引覆盖和检索方式，不将全文检索标为语义检索。

## 检索与写作

“文献与术语”中的“文献知识库”支持检索原文内容，返回对应书目、完整片段及页码。点击“查看原文位置”进入对应原件的具体页；每篇文献也可单独浏览、分页查看知识片段。

检索以当前项目的有效研究文献为范围，依次执行 BM25 与 Dense Retrieval 召回、RRF 融合、Cross-Encoder 重排，然后返回 Top-K 原文片段。默认两路各召回40个候选，去重后取40个融合候选交给本地独立重排模型。已归档、改为其他用途或排除的页面不进入当前知识库检索。原文和术语变化后，检索会刷新片段登记与全文索引；文本或模型版本不匹配的旧向量不参与语义排序，需要时增量更新。

RRF 使用各路排名计算融合分数，不直接相加 BM25 和余弦相似度的原始分数，同一来源在每路只计一次。Cross-Encoder 使用查询与候选原文共同打分，保留 RRF 排名和最终重排排名供核对。重排得分是相关性分数，不是事实正确率或概率；重排模型不可用、输出分数缺失或无效时保留 RRF 结果，并明确显示重排未完成。

知识库页面的“查看检索过程”显示各阶段候选数量、实际重排数量和耗时。返回数据保留实际执行的重排器、阶段状态与模型名称。检索评测分别记录 BM25、Dense、RRF 与最终重排的 Recall、MRR、nDCG；程序测试和排名变动不自动成为人工语义精度提升的证明。

普通写作的研究依据检索已连接该知识库，保留来源编号、书目关联与知识文档版本。原文来源和适用规则仍按原有写作清单记录。有据写作新增 `search_literature` 和 `read_literature` 工具，可从知识库定位原文并建立 `literature` 文献证据；文献依据不自动成为本项目的运行或测量结果。

本地检索可查看本机资料；向模型发送的检索结果会按文件及派生来源的外发权限过滤。工具缓存记录内容与权限状态，原文、权限或页面适用性变化后不会复用旧观察。片段可检索不代表其内容已经人工核对或足以支持论文中的具体论断。

## 验证

执行了知识库持久化、重复同步、项目隔离、页面排除、外发权限、索引增量、旧向量失效、文献证据工具及既有文献与写作流程的回归测试。浏览器另核对真实混合检索、片段分页、精确原页跳转、失败重试和移动端布局。

实际知识库任务与审计记录保存在本机 `.runtime/reference-knowledge-live-job.json`、`.runtime/reference-knowledge-live-audit.json` 和 `.runtime/reference-knowledge-browser/report.json`，不进入源码仓库。审计核对原件哈希、书目记录与来源编号保留情况，并确认没有新增付费模型调用。

完整重排链路的本机实测另保存在 `.runtime/rag-rerank-live-report.json`，记录实际查询、融合候选、重排结果与各阶段耗时，不代填人工相关性标注。
