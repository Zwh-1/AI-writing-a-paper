# 0.7.1 知识库功能补齐与验收说明

日期：2026年10月28日，Asia/Shanghai。程序版本0.7.1，数据库schema 14。

本次补齐软件功能并保留真实验收状态。软件能力、实际资料编译、人工质量评审、服务商账单及外部设备验收是不同的完成条件，不能互相替代。

## 新增功能

| 功能 | 当前实现 |
| --- | --- |
| 统一查询路由 | 自动解释问题类型、预算与索引可用性；按需要选择原生、Global、Local、DRIFT。收费需要明确启用和任务预算。显式选择的官方后端不可用时返回阻断，不能以原生结果冒充官方成功 |
| 结构化论证计划 | 返回候选论点、文献归属、支持与反证、限定条件、指标/单位/比较对象、不可比原因、拟读原文与缺口。完成阅读和支持性核对前仍保持候选身份 |
| 持久维护队列 | 逐项保存支持性检查、Wiki主题/比较/分歧综合、过期社区重建的检查点，取消六页上限。预算阻断保留剩余任务；执行不明不自动重发；检查后变化的论断重新取得当前版本 |
| Wiki三方合并 | 编辑冲突保留基础、本地、候选内容；不重叠编辑自动提出合并，重叠编辑逐块选择或手工修改；双方改序需要明确顺序。合并产生候选，不自动发布 |
| 支持性裁决 | 有效人工判断优先于模型候选；相同依据上的冲突需要裁决。裁决追加保存、绑定判断集合指纹；新判断使旧裁决需要复查，原记录不覆盖 |
| 完整评测统计 | 保留A/B/C/D，增加D组官方社区子对照；冻结原文与模型配置指纹。汇总Recall、MRR、支持性、限定条件、比较有效性、矛盾识别、错误引用、无依据扩写、修订次数和完成时间，并报告Wilson区间与分母 |
| 评审历史 | 人工评审逐次追加留存；不以未标注草稿或空分母计算95%达标。盲审揭示有审计记录 |
| 完整知识包 | 包含项目原件、证据、知识对象和历史、模型账本、资源及哈希。排除全局凭据与设备身份。现有Markdown包仍为阅读导出，完整包为迁移/恢复用途 |
| 隔离恢复与分支导入 | 原ID可恢复到隔离数据目录；显式导入新项目分支会映射ID并在隔离副本重验依赖。已有项目不被覆盖。GraphRAG物理索引在分支后需重建，原始字节和映射保留 |
| 完整知识云传输 | HTTPS WebDAV、Scrypt派生密钥、AES-GCM加密、ETag防覆盖；仅本地资料及未启用分享会阻止上传。拉取先预览；冲突保留为隔离副本/项目分支，不丢弃另一端数据 |
| 完整备份资源 | 本地备份增加知识产物文件，恢复到隔离目录时重新绑定资源路径，保留源文件校验 |
| 完成状态与人工材料 | 状态接口分别返回软件能力、语义覆盖、人工标注、账单缺口和外部验收。导出80项人工标注材料，仅提供定位建议，不代填人工答案 |

“文献与术语 → 图谱与Wiki → 维护与迁移”提供上述操作；“章节准备”显示论证计划。旧编辑入口遇到冲突会进入维护界面，原编辑内容保存在冲突记录中。

## 真实项目执行结果

- 已对31份研究用途原件启动全量AI语义编译。费用治理在发送收费请求前阻断：项目仍有21笔、12.41768 USD历史费用预留待核实。本次没有清零预留、增加预算或绕过约束。
- 已建立3,604项持久维护计划，涵盖尚需辅助核对及综合的实际来源。排队不代表语义处理完成。
- 已导出80项人工标注材料，保留未标注状态；核对人、真实盲审结论和通过率没有代填。
- DRIFT当前准备检查仍被同一费用条件阻断；原先HTTP 524请求没有自动重复发送。
- 真实本地查询两并发120秒完成86次请求，无错误；P50约2.88秒、P95约3.16秒。范围为原生图谱/Wiki导航，不包含独立神经原文检索，也不能替代24小时负载或清洁设备验收。

完整知识包有独立于应用发行包的大小限制：最多1.2GB压缩体积、2GB解压体积；当前原件登记约608MB，不能用“500MB以下应用安装包”限制用户资料的完整备份。

1. 服务商21笔历史请求的可匹配收费明细、费用字段语义及凭证真实性；没有这些依据不能释放预留或继续新收费。

4. 用户真实论文的效果对照；实际原文引用、不可比条件与论文修改结果应逐项验收。
5. 另一台清洁Windows机器和至少24小时真实负载。本机隔离目录、便携解压运行和短时负载分别记录，不会写成另一台设备通过。
