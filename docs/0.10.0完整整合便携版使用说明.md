# 0.10.0 完整整合便携版

本版发布文件为“砚台论文工作台_0.10.0_完整整合便携版.zip”，将当前已实现的研究工作区、产物互通和核心写作优化整合为一个便携包。

包内包含Python、Node、PowerShell 7.6.5 Core、截图浏览器、中文向量/重排模型和GraphRAG运行库。本地检索资源不需要首次下载；AI写作仍需在“接口与设置”配置自己的模型、密钥与预算。此完整整合版不适用历史精简包的500MB上限。

## 使用

1. 将整个ZIP完整解压到一个新目录。
2. 双击根目录“启动工作台.cmd”，使用包内经过版本校验的PowerShell启动。
3. 创建项目或从旧工作台备份恢复项目，再配置模型接口。
4. 退出时双击“停止工作台.cmd”。

发行包不含用户论文、项目数据库、会话或API密钥。升级已有项目使用备份/恢复功能；不要用新目录覆盖旧项目数据。Windows OCR语言包、Office渲染、Docker执行能力按宿主环境实际状态显示。

## 写作能力

- 自动检索资料、规则、文献和已授权毕业项目素材，实际读取后形成有版本的依据包。
- 可编辑逐章论证计划；长章按论证单元生成，支持检查点恢复。
- 主张级原生引用、独立核验、有限轮次补证与局部修订，保留正确论断和原引文。
- 章内、跨章及已读来源的重复风险检查；不将本地相似度换算成外部查重率或AIGC率。
- 整篇、单章、修订、补全和有据写作使用共享来源政策；核对权限、来源版本、研究成果等级和预算。
- 候选中可展开“素材与写作核验”，查看已读、已用、原文定位和未决缺口。

实施范围及真实模型验证边界见“核心写作与素材闭环实施记录_2026-11-03.md”。

## 校验

ZIP同目录提供SHA256校验文件。包内“便携包清单.json”记录源码提交、构建时工作区状态、文件清单及逐文件SHA256。构建时逐项复核文件；解压验收使用包内运行时和隔离合成项目，不读取个人论文，也不调用收费模型。
