# 独立学术润写

“润写”是独立写作操作，使用 `academic_polish.v1` 规范和独立提示词，不复用定向修改的生成流程。它先阅读所有已保存章节，再逐段改善措辞、语法、句式、学术语体和承接。不以扩写、压缩、事实纠错或重构论证为目标。

规范要求保留原有论点、事实、数值、单位、否定、条件与计划或完成状态。原文有事实或论证疑点时列入待核对问题，另用定向修改或补证处理。没有可编辑原文、选区被锁定或只有标题图表时，不调用模型。

论文规则中的“适用写作操作”可单独勾选“润写”，包括设置只适用于润写的条款和条件。润写只加载规则包中明确包含 `polish` 的已发布条目。旧规则包保持不变；仅适用于修改的条款不自动映射到润写。没有润写项目条款时，仍执行独立的内置润写规范；需要套用学校或项目的特定条款时，勾选“润写”后重新发布规则包。

输出逐一绑定原段落编号，段落数量和顺序不变。标题、图表、锁定段落、选区外正文、原段落来源与事实关联由程序保留。引用、脚注、带格式的文本片段使用原样保留标记，模型不能另写引用编号或添加文献、事实关联。

独立检查核对段落对应及顺序、保留标记、数值和常见单位，以及否定、条件、不确定性与完成状态的关键标记。发现改数值、改单位、遗漏保留片段、删条件或清空段落等问题时，保留原始输出与原因，候选不能直接采用。检查基于文本锚点，不能证明所有语义均保持不变；通过后仍是待审阅候选，不自动成为人工确认。

调用记录保留规范版本、规范哈希、润写目标段落、完整原稿哈希、所加载的独立项目规则与全文上下文版本。验证使用隔离数据和模拟模型，不以程序检查代替真实论文的人工语义审核。
