# 单文件便携版使用说明

> **0.7.3 更新**：当前交付采用[完整整合便携版](0.7.3完整整合便携版使用说明.md)，知识图谱运行库、截图浏览器及默认本地模型全部置于一个 ZIP 中。以下首次自动下载的说明适用于历史 `full` 精简发行配置。

使用 `砚台论文工作台_0.6.1_完整便携版.zip`。只需下载这一个 ZIP，全部功能代码与程序运行库随包保留；较大的截图浏览器、默认中文检索模型和重排模型在首次启动后自动下载，不需要另找或安装组件包。

## 启动

1. 将 ZIP **完整解压**到一个固定目录；不要在压缩包预览窗口里直接启动。
2. 双击 `启动工作台.cmd`。它调用包内的 PowerShell **7.6.5 Core**，严格核验版本后启动本机服务与任务进程，并打开浏览器。首次启动请保持联网，截图浏览器与两个默认模型在独立后台进程准备，不占用论文任务进程。
3. 首次使用在“接口与设置”填写模型地址和个人 key。生图使用独立的 gpt-image-2 设置与 key；保存设置不会发起收费生成。
4. 使用结束后双击 `停止工作台.cmd`。窗口关闭不会自动删除项目。

默认本机地址为 `http://127.0.0.1:8765`。项目和历史版本保存在解压目录的 `data` 下；升级时保留并正确迁移这个目录。密钥采用当前 Windows 用户的 DPAPI 加密，换账户后应重新填写。

## 包内已经具备

- Python 和后端依赖，包含文献解析、本地 OCR 的调用库、图表、三线表、Word/PDF 导出和统计分析。
- 构建后的前端，Node 与 TypeScript 解析运行时。
- PowerShell 7.6.5 Core，用户无需手动安装其他 PowerShell 版本。
- Playwright，以及 BGE small 中文向量模型、BGE reranker 重排模型所需的 ONNX 推理库。

## 自动准备的资源

首次启动自动准备 Chromium headless shell、`BAAI/bge-small-zh-v1.5` 和 `BAAI/bge-reranker-base`。模型通过 Git/LFS 内容哈希校验，准备完成后还会核对 SHA256；浏览器通过随包 Playwright 下载匹配版本。成功下载的资源存入 `.runtime`，下次启动直接复用，复制整个已准备好的目录也可继续使用。

写作、资料解析、本地 OCR、图表、统计和文档导出可在资源准备期间使用。截图与本地语义检索需等待对应资源就绪；截图仍需先登记实际研究系统地址，项目是否启用混合检索仍按项目设置决定。

双击 `准备便携资源.cmd` 可在窗口查看准备结果或重试失败资源；已校验的模型不会重复下载，模型中断下载可续传。后台进度和失败原因记录在 `.runtime/portable-resources.log`、`.runtime/portable-resources.json`；打开的工作台也提供需会话认证的 `/api/v1/advanced/portable-resources` 状态接口。默认模型下载先尝试镜像，失败时尝试官方源。整个过程不使用模型 API key、不上传论文。

小于 500 MB 的限制指发行 ZIP。首次自动下载后，程序目录会增加浏览器和模型文件的占用；这些文件与项目数据分别保存在 `.runtime` 和 `data`。需要首次即完全离线的开发发行可显式打包 `--profile offline`，该模式不受默认 500 MB 上限约束。

## 仍需由使用者提供的条件

AI 请求需要自己的接口、key、网络及账户额度。Windows OCR 需要对应中文／英文语言包。容器隔离代码执行需要可运行的 Docker 引擎；工作台不会为了“免安装”改用不隔离的宿主机执行。学校指定 Office 的精确分页与字段更新，需要相应 Office/WPS 环境；普通 DOCX 文件生成无需 Word。

上述条件不通过用户论文、账号密钥或别人的系统环境打包替代。ZIP 中不包含用户项目和个人凭据。
