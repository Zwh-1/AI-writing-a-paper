# 功能互通完整性复查与补齐

复查开始于 2026-11-02，补齐与最终验收于 2026-11-03。项目：砚台论文工作台。

## 结论和范围

上一轮的 15 类目录并没有覆盖所有现有内容产物。此次按“是否能发现、读取真实内容、进入下游、保存来源、处理版本变化和恢复操作”重新检查，补齐以下实现缺口。原有 106 项项目功能审计已重新生成：106 项都能定位到实现或功能等效路径，其中 35 项仍有外部服务、平台或运行条件；这不等同于 106 项已在所有真实环境验收。

## 已补齐的缺口

| 缺口 | 实际实现 |
| --- | --- |
| 规则、提纲、检查、证据等没有互通入口 | 目录从 15 类扩展为 31 类，增加论文规则、规则包、章节计划、检查意见、导师意见、问题阅读、证据、原文片段、结构化原文、自由画布、结构化解析结果、正文候选、文献发现结果、正文评论、交付记录、代码与截图执行结果 |
| 只能追加原样文本，写作功能不能直接使用选中产物 | 新增“关联本章写作材料”；普通逐章写作和有据写作的实际模型输入包含材料内容、来源和未核验身份，沿用现有预算检查与采用检查 |
| 产物不能补充计划或转交检查 | “补充章节计划”更新真实章节目标并保存原值及来源；“加入修改检查待办”进入现有导师意见/修改待办服务 |
| 富文本流转损失结构 | 随记、资产、章节草稿沿用结构化节点，保留标题、列表、样式、表格、图片、公式、脚注和文献引用；复制时分配新节点 ID，避免覆盖源内容 |
| 富文本在随记或资产编辑器中再次保存会丢失论文节点 | 公共编辑器增加论文节点和来源属性扩展，正文专用内容可显示并保留，保存后可继续用于正文；文献引用在采用后形成正式引用记录 |
| 旧随记追加入口仍只使用纯文字 | 旧入口委托同一套产物复用服务，也支持富文本、空章节和本地权限内容；随记页可直接启用或关闭关联章节写作材料 |
| 真实截图出现在目录中却不能保存到正文 | 正文支持 figure、image、screenshot 三类图像资产；下载与预览按实际图片字节提供 MIME 类型，保留原资产分类和本地权限 |
| 空章节不能接收草稿，本地内容被当作远程上下文检查 | 互通草稿使用本地上下文快照，空章节可以建立第一版正文，本地权限内容可本地复用；真实模型请求仍检查外发权限 |
| 只能从目录第一页打开产物 | 新增按类型和 ID 直接读取接口，不依赖当前分页；原文资料支持正文关键词搜索 |
| 选区、未采用草稿和会话材料切页后丢失 | 项目位置状态合并最新值并通知同页组件；保留已选产物、目标章节、筛选和草稿 ID；会话保存所选产物，刷新和切页后恢复 |
| 无法回到原功能 | 每条产物提供“打开原功能”；可准确定位随记、资产、画布、会话和候选，亦可打开规则、计划、检查、交付与原文 |
| 网页复用引用未打包的可选 HTML 库 | 改用 Python 标准库提取可见文本，排除脚本、样式和模板内容；网页记录与网页资产都可复用 |
| 证据入口缺少统一归属适配，可能绕过派生资产权限 | 增加证据归属校验，资产证据继续追溯来源权限；智能体按所选类型检查正文、资产和随记能力 |
| 重新检查删除了已被复用的旧意见 | 已引用意见保留为 superseded，历史来源不悬空；新检查继续替换当前展示，旧意见关联内容标为需复查 |
| 变更通知不完整 | 补齐规则、批量规则、章节计划、问题阅读、导师意见等通知；依赖指纹同时包含上游版本，漏通知时使用前仍能发现过期 |
| 跨功能来源的循环导致无限递归 | 资源版本检查增加调用范围内的循环检测，递归引用返回明确冲突 |

## 31 类产物与目标能力

内容目录包括：原始资料、资料总结、文献书目、思维随记、阅读批注、学术译文、阅读导读、助手回复、交互网页、研究资产、研究事实、统计分析、Wiki 页面、图谱论断、章节正文、论文规则、已发布规则包、章节计划、检查意见、导师意见、问题阅读、证据、原文片段、结构化原文、自由画布、结构化解析结果、正文候选、文献发现结果、正文评论、交付记录、代码与截图执行结果。

下游操作包括：转随记、共享资产、学术对话、章节草稿、图表插入、章节写作材料、章节计划和修改检查待办。界面按实际类型启用操作；图片使用图像插入，原生三线表保留单元格。配置、费用账本和密钥继续由各自功能管理，不作为事实证据复制到正文。

未采用候选、模型回复和个人随记始终保持未核验身份。来源版本、项目边界、锁定段落、正文版本和外发权限沿用原有机制。转换不产生模型费用；模型操作仍需用户点击其执行按钮。

## 使用与实际验收边界

更新后的源码和前端构建已保存，重启源码工作台后从“研究与协作 → 产物与互通”使用。原安装器及便携 ZIP 没有在本轮重新打包。

总结、事实和统计结果的依赖指纹已增加上游版本。旧算法生成的引用可能保守标为需要复查；原内容和历史保留，重新选择当前产物即可生成有效新引用，不会静默把旧依据升级为已核验。

本轮完成源码和本地流程可实现的补齐。Docker/GPU、Zotero/OpenAlex/MinerU/Modal 等真实服务、macOS 构建安装和远端 CI 发布仍依赖对应环境或账号；不将模拟测试写成这些环境已实测通过。完整学校复杂模板和实时多人协作等原项目未承诺的能力不在此次互通补齐范围内。
