# 写作表达优化：先提示词，后程序

## 目标与材料

将“改善自然表达、论证和衔接”落实到论文生成、定向修订、独立润写及既有核验流程。用户截图记录 AIGC 54.97%、上一轮54.59%；这是截图中的历史结果，不是本轮新检测，也不能证明程序修改后的效果。

本轮先编写 `prompts/academic-expression.v1.txt` 与 `academic-expression-review.v1.txt`，再接入代码。主要依据为 `D:/桌面/xiezuo/写作流程/md-thesis-writing/references/论文语言与原创表达.md`、`审查规则.md`，并参考旧资产中的 `references/writing/aigc-style-governance.md` 和 `chapter-quality-checklist.md`。

这些文件是参考材料。其中关于时间银行题目、旧路径、固定段首引文、单篇只引一次、具体文献配额、旧脚本命令及旧工作流的指令不自动成为当前论文工作台的全局规则。当前项目已确认规则、真实证据及本次操作范围仍决定可写内容。

四份参考文件的实际路径及 SHA-256 保存于 `docs/academic-expression-sources.v1.json`。生成使用内置提示词文件，不依赖外部 xiezuo 目录在运行时存在。

## 优化后的提示词

共享写作提示按“具体问题—对应依据—必要解释—自然承接”组织指导，但不要求每段套用这个结构。规定明确主体与指代、按信息量分段、按本节职责组织材料，纠正空泛与重复表达，保留准确术语、事实、引用与限制。范例不提供本项目成果，不用虚构经历、随机换词或固定句式变化改善表面文风。

共享核验提示要求给出原文位置、具体问题与最小修订方向，不按词频和段长评分，不把局部原文核验冒充全文审查。润写沿用原有逐段和受保护片段契约，不能擅自重构论证或增加事实。

## 程序接入目标

- 同一版提示进入普通写作、整篇写作、agent 起草和修订、独立润写；核验使用独立表达审查提示。
- 自动段落计划只作建议，不以段数差异要求补写空话；明确的用户规则及内容覆盖检查继续生效。
- 自动分配段落职责时避免剩余篇幅全部重复最后一个任务，并使用本节真实任务点。
- 分单元生成保留前序原文及当前任务卡，按内容承接，单元中不重复章节开场和总结。
- 按任务点编号匹配单元段落职责，避免任务卡与段落计划分别切片造成重复或提前写下一单元。自动关系标记为尚未核验的建议，实际注册论证关系不改写。
- 局部核验仅保留本次实际提供范围内有段落定位的发现，避免未读段落上的猜测进入后续修订。

## 验证口径

离线测试验证实际请求携带新提示、任务点与段落分配、单元承接、证据与引用保护、润写范围和既有写作回归。测试通过不代表真实模型写作质量已通过人工审阅，不代表外部 AIGC 检测下降；本轮不以本地指标代替检测结果。

新增提示词会占用输入上下文，程序仍按实际请求检查容量，超限保留候选并报告。容量恢复测试的固定预算已包含新版提示占用，不放宽实际容量保护。

## 使用

本轮修改的是 `D:/桌面/论文/paper-workbench` 的源码与提示词。重启该目录的工作台后，新建生成或定向修改任务使用新版；旧任务的已完成候选和调用记录不会自动改写。已有完整便携版 ZIP 未重新打包。没有进行真实付费模型生成、整篇论文重写或外部检测复测。
