# 0.3.4：DeepSeek 主模型与 GPT 备选

日期：2026-10-22。

## 本机已生效的配置

| 用途 | 接口 | 模型 |
| --- | --- | --- |
| 默认写作、规则提取、提纲、检查及图片识别 | https://api.x5m5x.com | deepseek-v4.1-flash-1017 |
| 资料总结 | 原有独立 DeepSeek 总结配置 | deepseek-v4.1-flash-1017 |
| GPT 备选 | https://www.ecoapi.cc/v1 | gpt-6.1-sol |

GPT 模型来自当前账户实际返回的列表，启用权限后已重新查询。地址拼接避免重复 `/v1`。GPT 5 及后续模型的 Chat Completions 请求使用 `max_completion_tokens`；DeepSeek 仍按兼容协议发送 `max_tokens`。

主接口复用已有 DeepSeek 总结密钥，原 EcoAPI 密钥迁移到独立 GPT 凭据。三份配置通过 Windows DPAPI 加密保存，主接口、总结、GPT 的设置分别管理，接口响应仅展示脱敏状态。更换某一配置的密钥不会隐式覆盖其他配置。

当前主设置、模型默认值、前端协议选择以及普通和流式请求适配均已停用 Gemini。保存旧协议或旧模型会被拒绝。过去的任务、调用账目、诊断文档和恢复备份仍保留原始模型名称，不作为当前配置使用，也没有重发历史未决任务。

## 备选切换

默认任务使用 DeepSeek；图片接口在样本验证通过后已启用。尚未验证图片能力的安装可以先使用本地 OCR，或在 GPT 配置就绪时把图片任务交给 GPT。

DeepSeek 明确返回鉴权、额度、权限、模型不存在等拒绝，或明确说明不支持图片等能力时，可切换 GPT。明确限流在本次重试策略耗尽后也可以切换。每次调用独立记录实际接口、模型、凭据哈希、用量、费用预留和切换原因，仍执行资料外发限制、来源追溯、协作权限及项目预算检查。

超时、5xx、无效成功响应、已有输出或流式片段的请求不自动切换，不把可能执行过的调用当成未执行。任务中心提供“用 GPT 重试”，核实后确认可能重复计费才能提交；原任务历史和未决费用预留保留。

资料总结切换备选后，缓存及最终结果记录实际参与的模型。共用 DeepSeek 密钥时，账单核对纳入同一密钥、模型、接口的其他任务；只有账单范围、项目和 Token 数能够完整匹配时才调整未知费用预留。

## 实测与验证

三次独立实际能力调用全部成功：

- DeepSeek 普通生成返回可校验的 JSON。
- GPT 识别本地生成的图片字符 `A7X2`，返回内容与图片一致。
- DeepSeek 也识别了同一图片字符，返回内容与图片一致，随后开启主接口图片能力。

以上是样本验证，复杂图表和论文内容仍按原流程人工核对。实际调用已在任务中心和用量账目记录；没有填写服务商单价的调用仍显示费用未知，没有假定免费或擅自清除预留。

完整后端回归 394 项通过；最后新增的图片验证、禁止图片测试偷偷切换接口、未决任务改用 GPT 的确认校验等，连同路由回归共 23 项通过。前端类型检查及生产构建通过。

真实浏览器验证 5 项通过：主备模型与地址、密钥不回显、空白密钥保存保留原值、保存错误与模型权限提示、桌面及 390px 手机布局。浏览器检查未触发计费调用。

迁移前后核对了项目、文件、页面、来源、规则、规则包、事实、正文修订和书目内容哈希，全部一致：25 份资料、655 页、1246 条来源、438 条规则候选保留。未自动确认规则或改写论文正文。迁移前数据库保存在 `data/backups/before-deepseek-gpt-7a9e18adda9f4af686baabf5ff29d1cd.sqlite3`，其中不含 API 密钥文件。
