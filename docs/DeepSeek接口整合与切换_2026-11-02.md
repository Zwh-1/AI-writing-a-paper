# DeepSeek 接口整合与切换

原来的“资料总结设置”“多端点池”“主模型接口”合并为“接口与设置”页面中的一个 **DeepSeek 接口**列表。

## 使用方法

1. 点击“添加接口”，填写名称、HTTPS 地址、此接口的 API key 和实际 DeepSeek 模型 ID。
2. 可点击“保存并检测模型”，再从返回的模型 ID 中选择。检测失败不会清除已经保存的密钥。
3. 点击列表右侧的播放形切换按钮，绿色背景和“使用中”表示当前选择。
4. 通过铅笔按钮修改接口；API key 留空保留原密钥。
5. 更多操作中可以查询此接口的账户余额，或删除未使用的接口。正在使用的接口须先切换后再删除。

论文写作、资料总结、规则整理、文献阅读与知识库使用同一 DeepSeek 选择。GPT 备选与图片生成仍使用各自的设置和密钥。

## 配置迁移

首次打开接口列表时，会把旧主模型、资料总结和多端点配置迁入列表。相同地址、模型和密钥的配置合并为一个接口；不同密钥或模型保留为独立行。旧配置文件和迁移前配置仍保留，密钥不写入设置表或接口响应。

每个接口的密钥分别存储在 Windows DPAPI 加密的密钥集合中，前端仅收到脱敏后的末四位。切换后不需要重新填写密钥。

## 切换范围

默认手动切换，仅使用选中的接口。已经取得配置和凭据快照的请求继续使用原快照。新增接口只保存配置，不会自动切换或发起模型生成。

高级设置保留失败后切换、轮询、重试次数和熔断参数。手动点击某个接口的切换按钮会恢复手动模式。执行结果未知或已经返回内容的请求不会自动重发。

余额来自各服务商的查询接口，按接口保留查询时间；不支持查询时显示错误并保留上次结果，不将其当成零余额。模型检测和余额查询只作用于指定行，不会切换当前接口。

## 代码与验收

- 页面组件：`frontend/src/DeepSeekSettings.tsx`。
- 统一管理接口：`backend/app/deepseek_profiles.py`，路径为 `/api/v1/deepseek/*`，同时兼容现有 `/api/v2/deepseek/*` 网关。
- 原主模型与资料总结设置 API 在迁移后更新同一个当前接口。
- 后端回归：`tests/test_deepseek_profiles.py`、原多端点、模型路由、资料总结、余额、图片生成、费用核对相关用例。
- 浏览器验收：`tests/deepseek-settings-browser.cjs`，桌面与 390px 窄屏，测试密钥与模拟查询响应，没有收费模型请求。
- 浏览器验收报告：`deepseek-settings-browser-report.json`。
