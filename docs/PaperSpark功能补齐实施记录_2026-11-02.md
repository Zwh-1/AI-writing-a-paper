# PaperSpark 功能补齐实施记录

目标项目：砚台论文工作台。版本：**0.8.0**；数据库 schema：**16**。参照此前对照报告中的 Y01–Y29，补齐的是砚台项目的功能，并非修改 PaperSpark。

## 使用入口

左侧新增“研究助手”，包含“文献接入、论文阅读、学术对话、思维随记、自由画布、文献发现、TeX 与数据、解析与运行”。写作编辑器下方新增学术对话、选区评论、可视化公式、自由画布和光标补全工具。

重新启动主服务与 worker 后使用新版前端。迁移会先保存旧数据库副本，再创建版本化研究记录、历史、外部身份映射与 OAuth 状态表；旧正文、原件、书目和已有版本保持原身份。不要以旧版服务搭配新版页面判断功能是否可用。

## 逐项实现

| 编号 | 原缺口 | 本次实现及实际边界 |
| --- | --- | --- |
| Y01 | URL 直接导入 | 下载任务、跳转/类型/体积校验、原件哈希入库、原生解析、来源 URL 与书目关联；复用稳定书目 ID。 |
| Y02 | Zotero | 个人/群组库配置、API Key 与 OAuth、临时令牌过期/单次消费、全量分页、附件、来源主键映射及重复同步保留身份。真实账户授权待用户凭证验收。 |
| Y03 | 文献摘要翻译 | 直接翻译书目摘要，按原摘要哈希和目标语言保存，保持原摘要不变。 |
| Y04 | 标签 | 文献标签增删改、列表展示与筛选；后端支持批量 replace/add/remove。 |
| Y05 | 删除和资源回收 | 删除影响预览、当前库移除、索引清理/失效传播；历史原件与已被引用的书目保留。孤立对象另有预览/回收，保护所有持久记录和24小时内的新对象。 |
| Y06 | 双栏翻译 | 按原文解析版本与单元保存分块译文、续传/缓存、原译同一滚动区域、语言切换和阅读进度。原文变化后不会继续把旧译文显示为有效。 |
| Y07 | 结构导图 | 章节/段落树形图、层级线与点击定位；保留原解析单元与标题候选，不把结构推断当事实。 |
| Y08 | paper-ref | 参考区/编号范围解析、DOI/外链、引用信息、定位参考条目与返回引用段落。不同期刊的特殊引用格式仍可能需要专项适配。 |
| Y09 | 原文高亮批注 | 选区文本/字符区间/解析版本/哈希校验、多色高亮、笔记、列表、回跳和删除。当前实现锚定结构化原文文本；不是扫描图片上的自由矩形涂画。 |
| Y10 | 交互网页 | 论文 HTML 生成任务、版本保存、隔离 iframe、禁外部网络的预览与下载。生成内容仍为模型产物。 |
| Y11 | 通用助手 | 自定义角色/提示词/模型路线/知识、资产和文献能力；连续对话、来源信息、会话历史；原件权限在历史复用时重新核对。 |
| Y12 | 随记 | 富文本随记、标签、搜索、对话摘存、版本冲突检查与历史；概括/整理/润写/扩展产生候选，不静默覆盖原笔记。 |
| Y13 | 光标补全 | 从当前正文版本和光标取上下文，手动补全或显式开启输入后补全；接受前核对版本与完整文档快照，仍受段落锁定保护。 |
| Y14 | 评论线程 | 稳定段落选区评论、范围标记、回复、解决/重开和 AI 回复；已失效选区明确显示，模型不绕过正文来源权限。 |
| Y15 | 公式 | 固定版本 MathLive、本地字体资源、可视化/LaTeX 同步输入；行内数学节点、KaTeX 预览、Word OMML 与 Markdown/TeX 输出。 |
| Y16 | 自由画布 | 手绘/矩形/椭圆/线/箭头/文字、移动、删除、颜色线宽、撤销/重做、版本化场景、PNG、归档资产与正文插入；正文选中相应图形后可重新打开源场景。 |
| Y17 | Python 图片回填 | 带 matplotlib 的固定 Docker 镜像、可写隔离输出、图片类型/像素/体积/哈希校验、资产归档、聊天代码块运行及用于正文；本机 Docker 未启动，未在当前主机实际运行容器。 |
| Y18 | 远端执行 | local-container/remote-http provider、凭证设置、输入外发权限、统一文本/退出状态/图片协议与远端 broker；远端代码仍只在 Docker 子容器内运行。 |

| Y20 | LaTeX 工程 | main.tex、references.bib、Markdown、图片、编译说明、版本清单与转换提示 ZIP；中文/英文模板，实际合成样本经 XeLaTeX/pdfLaTeX 编译成功。 |

## 验证结果

- 前端 TypeScript 检查及 Vite 生产构建通过，公式字体随应用本地交付。
- 一组覆盖原流程及新增集成的 **238 项后端回归通过**。此后针对版本化记录、大量翻译缓存、API契约、打包选择再次定向检查，结果保存在 `.runtime/studio-acceptance-20261102/studio-final-results.xml`。测试均使用隔离目录和合成资料，没有操作真实论文库或请求付费模型。
- **15项浏览器场景通过**：标签、原译双栏、高亮笔记、导图、网页、会话、富文本随记、文献候选导入、画布、TeX下载、运行设置、正文评论+AI回复、行内可视化公式、光标补全和移动布局；浏览器无页面脚本异常或失败API响应。记录在 `.runtime/studio-acceptance-20261102/browser-results.json`。
- 在线/离线 CLI 的 summary/list/get/search **8个组合通过**。
- 合成英文正文含行内公式和表格，pdfLaTeX 编译成功；中文正文 XeLaTeX 编译成功。生成PDF已渲染查看。当前 MiKTeX 验收环境补齐了缺少的宏包，不把用户环境缺包误报为导出代码完成验收。
- PowerShell脚本语法、Python编译、JavaScript语法、YAML解析、`git diff --check` 通过。Shell要求统一为 PowerShell Core >7.6.0。

测试入口：`tests/test_studio.py`、`tests/serve_studio_fixture.py`、`tests/studio-browser.cjs`、`tests/verify_studio_delivery.py`。浏览器插件初始化失败后，使用项目已有隔离测试运行器；没有接触用户浏览器登录态。

## 数据与部署边界

本次没有自动升级真实运行库的数据库、重启正在处理论文的服务、调用外部真实账号、推送远端仓库、发布镜像或创建安装器产物。前后端源码版本同步到0.8.0；重启主服务与worker后迁移和新入口生效。原来已存在的接口适配修改保留，没有被覆盖。
