## 按模块的问题、优先级与处理

P1 表示会破坏任务一致性、恢复正确性或输入契约的实际问题；P2 表示一致性、防护或诊断改进；P3 表示需要代表性负载或人工评价后再推进的优化。本轮没有把尚未接入的外部服务列为现有功能故障。

本轮共处理 19 项：11 项 P1、8 项 P2，涉及 12 个后端模块。MCP 项交付的是能力诊断与现状修正，完整协议接入单列为后续工作。

## 需要关注的边界

1. 新对话任务发现智能体配置变化时返回 409，需要使用当前配置重新提交；模型已经返回的结果继续留在原请求账本，不自动套用到对话或正文。没有快照的历史对话任务保留读取当前配置的兼容路径，并在本次发送与返回边界进行检查。
2. 后续写作步骤继承会话原协议，不会看到之后新建的记忆或新技能版本；若意图使用新配置，应创建新会话。来源权限撤回仍优先，冻结不授予继续外发的权利。
3. 冲突记忆不能全部容纳时会整组延后，留下 `memory_conflict_budget`；仍需用户明确替代或解决作者决定冲突。
4. 技能输入预算现在包含宿主包装文字，原先恰好贴近上限的显式选择可能改为报超限；可提高项目技能预算或减少显式技能，而不是截断技能说明。
5. 检查点重复恢复只接受同键同内容。遇到冲突保留现有记录并返回 409；主业务库与检查点库仍是两个 SQLite 文件，不宣称具备跨库分布式事务。每次恢复可重复校验，归档原件和节点收据继续保留。
6. 图表的 unknown 表示缺少可验证的度量，不能当作通过；属性检查、SVG/PDF 产物存在与实际 Office 分页视觉验收是不同结论。
7. 本轮没有连接外部 MCP 服务或执行真实模型计费实验；不能据模拟传输测试推断服务商稳定性或论文语义质量。
8. 源码生效需要后续重启 API 和执行器。当前已运行实例和历史安装包仍可能执行旧实现；更新时应遵循现有运行身份与发布门禁流程。
