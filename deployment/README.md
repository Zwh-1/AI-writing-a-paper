# 协作服务部署

网关提供独立账号、项目权限、章节协作、批注、版本冲突与可配置预算的AI候选。原件准备、复杂Office处理与最终排版可以继续在Windows工作台完成，项目通过加密快照保持资源与引用一致。

## 本机使用

在“高级研究与协作 → 协作与云同步”建立首次管理员，明确允许目标项目共享，启动本机协作服务。默认只监听127.0.0.1:8774；浏览器登录后管理员建立成员账号。停止服务不会删除数据库或浏览器离线草稿。

## 公网Docker部署

1. 准备可运行Docker的服务器、自己的域名及80/443端口；域名解析到该服务器。
2. 复制.env.example为.env，填写PAPER_DOMAIN、API地址、协议与服务方真实模型ID。协作AI预算默认0。
3. 在PowerShell 7.6.5中运行上级目录的“部署协作服务.ps1 -CheckOnly”检查配置。运行不带CheckOnly的脚本时，会让用户自己填写key和首次管理员密码。
4. Caddy是唯一发布端口的服务，内部网关不直接发布HTTP端口；安全Cookie和Origin/Host检查以配置的HTTPS域名为准。
5. 通过HTTPS域名登录。导入项目资源快照，分配成员权限；原始Word/PPT精确渲染继续使用准备好的本机Office组件。Docker镜像不宣称包含Windows COM。

脚本将key保存在deployment/private/model-api-key.txt，作为Docker secret仅挂载给worker，不复制到镜像，网关及成员浏览器不能获取key。private、真实.env和用户data均不在发布包/镜像构建上下文。仅做文字协作时key可以留空，保持预算0。

## 初始账号与预算

管理员密码经标准输入送入runner.py collaboration-admin，不出现在进程参数中。已有账号再次建立同名管理员会被拒绝，应使用现有账号。

如需更改服务端协作总预算，在已登录的服务器终端执行Docker Compose的exec命令，运行 `python -I -X utf8 runner.py remote-ai-budget 数额`。该预算是本地记录和未知费用预留，不保证等于服务方实际消费上限；实际支出以服务方账单和账户额度为准。管理员再在协作账号目录分配个人额度。成员仍需已发布规则包才能生成论文候选。

## 数据与备份

paper_data卷保存SQLite、原件和修订。备份应使用一致性数据库备份及对应内容哈希对象，不能只复制正在写入的SQLite主文件。论文项目的加密云快照按项目选择，不携带全局服务凭据、管理员密码哈希或会话。服务器身份数据的运维备份由服务所有者分别管理。

现有实现面向受控团队，不把配置检查当作公网、容量、渗透测试或学校正式论文人工验收。默认不启用开放注册，不将主工作台的本机共享会话暴露为多用户登录。
